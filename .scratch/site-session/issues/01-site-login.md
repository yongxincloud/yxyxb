# 01: 网站会话模块接管登录

**Parent:** [架构深化与存量数据安全](../../architecture-deepening/spec.md)

**What to build:** 建立一个可独立测试的网站会话 module，接管密码登录、邮箱验证码发送与验证码登录、结构化响应解析、token/session 持久化和设备上限返回。现有 WPF 登录窗口继续正常工作，但只负责收集输入和展示结果。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 新 module 通过一个单次会话操作 seam 暴露可观察结果，测试不需要启动 WPF 窗口。
- [ ] 密码登录和验证码登录都能完成并保存与现有格式兼容的 token/session 文件。
- [ ] 验证码发送保留开发环境自动填充能力，生产行为不变。
- [ ] `DEVICE_LIMIT` 返回会保存受限会话、保留最大设备数和用户可理解提示，后续设备重登可识别。
- [ ] 网站响应使用结构化 DTO 映射，不再依赖正则表达式提取 JSON 字段。
- [ ] 网络错误、授权缺失、凭证错误和服务器响应异常保持现有用户可见语义。
- [ ] 现有登录窗口调用新 module 后，密码登录和验证码登录仍可端到端使用。
- [ ] 测试使用 fake HTTP 和临时文件目录，覆盖成功登录、验证码登录、设备上限、服务端错误和损坏会话文件。
- [ ] 本 ticket 不迁移设备列表、踢出和启动时设备一致性检查。
