# 03: 启动前预检、回滚与生产结构验收

**Parent:** [架构深化与存量数据安全](../../architecture-deepening/spec.md)

**What to build:** 在网站数据库启动前接入只读预检和一致备份门槛，完成生产结构升级、重复启动和失败回滚验收。任何预检失败或迁移失败都必须停止启动，不继续运行半升级 API。

**Blocked by:** 02 - 产品目录与管理员 seed 初始化

**Status:** ready-for-agent

- [x] 启动流程在数据库变更前调用预检与一致备份，失败时停止而不是继续服务。
- [x] 迁移失败后保留备份、报告和已执行步骤，回滚流程可恢复到原数据库。
- [x] 使用脱敏生产结构验证升级前后客户、订单、支付、授权、设备、服务商、佣金、结算、开票和产品语义一致。
- [x] 验证重复启动、升级中断后重试、备份空间不足和只读权限失败。
- [x] 验证旧产品、部分客户资料、设备限制、佣金快照和开票关联仍可读取。
- [x] 启动日志只记录版本、迁移编号、行数级别检查和失败阶段，不记录客户明细或凭据。
- [x] 不修改生产服务器，仅交付工具、测试和人工操作清单。

## Comments

2026-11-10：启动入口已收口为单一数据库启动 module，共用 `YxyXb.Database` 预检 module。生产副本演练通过，迁移前后业务语义指纹一致，源副本哈希未变化。启动测试覆盖一致备份、回滚恢复、迁移失败报告、中断重试、重复启动和无效数据库；预检测试覆盖空间不足、写入失败和报告脱敏。Linux/FTP 人工上线与回滚步骤见 `docs/operations/database-upgrade.md`。
