# 03: 启动前预检、回滚与生产结构验收

**Parent:** [架构深化与存量数据安全](../../architecture-deepening/spec.md)

**What to build:** 在网站数据库启动前接入只读预检和一致备份门槛，完成生产结构升级、重复启动和失败回滚验收。任何预检失败或迁移失败都必须停止启动，不继续运行半升级 API。

**Blocked by:** 02 - 产品目录与管理员 seed 初始化

**Status:** ready-for-agent

- [ ] 启动流程在数据库变更前调用预检与一致备份，失败时停止而不是继续服务。
- [ ] 迁移失败后保留备份、报告和已执行步骤，回滚流程可恢复到原数据库。
- [ ] 使用脱敏生产结构验证升级前后客户、订单、支付、授权、设备、服务商、佣金、结算、开票和产品语义一致。
- [ ] 验证重复启动、升级中断后重试、备份空间不足和只读权限失败。
- [ ] 验证旧产品、部分客户资料、设备限制、佣金快照和开票关联仍可读取。
- [ ] 启动日志只记录版本、迁移编号、行数级别检查和失败阶段，不记录客户明细或凭据。
- [ ] 不修改生产服务器，仅交付工具、测试和人工操作清单。
