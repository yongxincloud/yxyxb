# 02: 产品目录与管理员 seed 初始化

**Parent:** [架构深化与存量数据安全](../../architecture-deepening/spec.md)

**What to build:** 将产品目录、试用配置和管理员初始化迁入独立 seed module。已有产品、促销、排序和历史旧产品保持原值，管理员密码只在首次创建或明确配置重置时更新。

**Blocked by:** 01 - Schema 基线与现有迁移

**Status:** ready-for-agent

- [ ] 只有不存在产品时才创建种子产品；已有产品和历史下架产品不被覆盖或删除。
- [ ] 试用价格等系统配置缺失时可补齐，已有配置值不被静默重置。
- [ ] 管理员首次创建、邮箱补齐和密码重置行为与当前配置语义一致。
- [ ] 旧数据库升级后仍能解析历史订单引用产品，即使产品当前已下架。
- [ ] seed 操作幂等，重复启动不会生成重复产品、配置或管理员。
- [ ] 测试覆盖空库首次启动、已有目录升级、旧产品保留和管理员配置。
