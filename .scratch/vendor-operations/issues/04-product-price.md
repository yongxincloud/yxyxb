# 04: 产品与价格 module

**Parent:** [架构深化与存量数据安全](../../architecture-deepening/spec.md)

**What to build:** 将产品原价、促销窗口、设备上限、排序和上下架规则移入产品与价格 module。营销页、门户和厂商页面继续读取相同产品语义。

**Blocked by:** 03 - 结算与开票 module

**Status:** ready-for-agent

- [ ] 原价、促销价、起止时间、设备上限、排序和上下架校验保持现有口径。
- [ ] 清空促销价会同步清空促销起止时间，非法促销窗口被拒绝。
- [ ] 产品更新保留操作前后证据和操作日志。
- [ ] 历史已下架产品和历史订单引用的产品不被删除或替换。
- [ ] 营销页、门户和厂商页使用同一产品当前价、促销状态和设备上限规则。
- [ ] 测试覆盖价格、促销过期、设备上限、上下架、排序和历史产品解析。
