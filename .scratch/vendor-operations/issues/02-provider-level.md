# 02: 服务商与等级 module

**Parent:** [架构深化与存量数据安全](../../architecture-deepening/spec.md)

**What to build:** 将服务商申请审批、等级创建与调整、启用停用和冻结规则移入服务商与等级 module。现有厂商接口、客户归属变化和操作日志保持兼容。

**Blocked by:** 01 - 客户与授权运营 module

**Status:** ready-for-agent

- [ ] 服务商申请审批保留等级校验、服务商编号生成、申请状态更新和失败原子性。
- [ ] 等级创建与比例修改保留 0 到 1 范围校验、唯一名称约束和操作日志。
- [ ] 服务商启用、停用、调级和冻结保留已解约状态限制及错误提示。
- [ ] 冻结服务商时，其直属客户解除归属的行为和返回数量保持不变。
- [ ] 服务商、等级和客户归属查询继续提供现有页面所需字段。
- [ ] 不重算历史佣金比例快照、佣金明细或结算关联。
- [ ] 测试覆盖审批、重复审批、改等级、冻结、状态限制和日志证据。
