# 05: 厂商运营兼容契约

**Parent:** [架构深化与存量数据安全](../../architecture-deepening/spec.md)

**What to build:** 在四个运营领域迁出后，让厂商 controller 只保留认证、请求和响应适配，并冻结厂商 API、操作日志与存量业务数据兼容矩阵。

**Blocked by:** 04 - 产品与价格 module

**Status:** ready-for-agent

- [ ] 厂商 controller 不再直接组合客户、授权、服务商、结算、开票和产品写操作。
- [ ] 现有厂商 HTTP 路径、请求字段、响应字段和主要错误提示保持兼容。
- [ ] 客户搜索、看板、设备、授权、服务商、结算、开票、邮件和日志页面回归通过。
- [ ] 兼容矩阵覆盖 16 个客户、62 个订单、15 个支付、37 条授权和 1 个服务商的脱敏生产结构样本。
- [ ] 已下架旧产品、部分客户资料、设备限制、佣金快照和开票关联仍可解析。
- [ ] 测试工程加入 solution，构建无新增警告，厂商运营测试全部通过。
- [ ] 不修改生产数据库结构，不连接生产服务器，不记录客户明细或凭据。
