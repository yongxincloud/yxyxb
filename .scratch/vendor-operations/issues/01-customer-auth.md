# 01: 客户与授权运营 module

**Parent:** [架构深化与存量数据安全](../../architecture-deepening/spec.md)

**What to build:** 将厂商端客户搜索、授权发放、账号类型变更、服务商归属和客户删除规则从大型 controller 移入一个可测试的客户与授权运营 module。现有 HTTP 行为和厂商操作结果保持兼容。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 授权发放保留定制版设备上限校验、到期日计算、宽限期续期基准、操作日志和站内消息。
- [ ] 账号类型变更保留有效期不变、设备上限变化、原因记录、操作日志和站内消息。
- [ ] 客户搜索、服务商归属和客户删除使用同一 module，不再由 controller 组合数据库写操作。
- [ ] 客户删除保持现有硬删除语义，并覆盖订单、支付、佣金、授权、开票、消息、令牌、登录日志和设备关联。
- [ ] 不重写订单金额、支付状态、授权到期日、佣金快照或历史开票关联。
- [ ] 现有厂商客户页和授权接口的请求、响应与错误提示保持兼容。
- [ ] 测试使用临时 WebDb 和 HTTP 入口覆盖授权、改类型、归属和删除；不访问生产服务器。
- [ ] 本 ticket 不迁移服务商等级、结算开票和产品价格规则。
