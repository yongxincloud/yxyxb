# 03: 结算与开票 module

**Parent:** [架构深化与存量数据安全](../../architecture-deepening/spec.md)

**What to build:** 将佣金结算审批、付款登记和开票处理移入结算与开票 module。厂商页面和门户现有的业务状态流转保持兼容。

**Blocked by:** 02 - 服务商与等级 module

**Status:** ready-for-agent

- [ ] 结算审批保留发票文件、当前状态和合法流转条件。
- [ ] 付款登记保留流水号必填、付款时间、状态更新和错误提示。
- [ ] 开票申请处理保留订单与客户关联、状态流转和金额语义。
- [ ] 结算与开票查询继续返回现有页面所需字段，不泄露额外客户资料。
- [ ] 不重写已结算佣金、历史付款流水或已开票订单关联。
- [ ] 失败写入不留下半完成状态，重复请求按现有行为处理。
- [ ] 测试覆盖审批、付款、开票、非法状态、重复操作和客户/订单关联兼容。
