# 02: 过期备份单元清理

**What to build:** 云清理按同一备份单元的清单和分卷判断过期，分卷先删、清单最后删，失败立即停止。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [x] 同目录多组备份单元不会互相混合。
- [x] 任一分卷未过期时整组保留。
- [x] 删除严格按分卷后清单执行。
- [x] 分卷删除失败时不删除清单。
- [x] 空前缀和产品前缀外对象不会进入删除批次。
- [x] 独立旧 ZIP 可删除，孤立分卷保留。
