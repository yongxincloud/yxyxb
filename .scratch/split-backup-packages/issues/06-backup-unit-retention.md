# 备份单元整体删除与保留

Category: enhancement  
Status: ready-for-agent  
Type: AFK

## Parent

[分卷备份包与运行统计](../spec.md)

## What to build

本机、网络共享、FTP 和每个云服务商都把外部清单、全部分卷和内嵌文件视为一个备份单元。“上传后立即删本地包”和按天自动删除只在完整单元满足条件时执行，先删分卷，最后删清单，避免留下孤儿文件或指向残缺数据的清单。

## Acceptance criteria

- [ ] 普通单 ZIP 继续按原规则清理。
- [ ] 分卷单元只有在全部文件都超过保留时间时才删除。
- [ ] 立即删除同时清理完整 ZIP、分卷目录和外部清单。
- [ ] 分卷删除失败时保留清单并记录完整错误。
- [ ] 云对象按相同产品前缀和备份标识分组清理。
- [ ] 不删除其它产品或不属于该备份单元的对象。
- [ ] 测试覆盖整组过期、单文件未过期、缺卷和不支持原子删除的错误记录。

## Agent Brief

**Category:** enhancement  
**Summary:** 让手工删除、立即删除和按天保留都以完整分卷备份单元为单位，避免孤儿分卷或残留清单。

**Current behavior:**

本机、网络共享和 FTP 清理只扫描 `.zip` 文件，并按每个文件自己的修改时间独立删除。五个云适配器也明确只处理名称以 `.zip` 结尾的对象。

当前没有备份单元概念，也没有“整个目录全部过期才删除”的规则。外部 `.manifest.json` 不会被现有云清理或 FTP/网络共享清理识别；分卷模式下可能保留清单或部分分卷。

**Desired behavior:**

分卷目录中的外部清单、全部数据分卷和任何内嵌内容构成一个备份单元。自动保留和“上传后立即删除”都操作整个单元，不按单个分卷独立决定。

自动删除时，只有外部清单存在、清单要求的全部分卷存在，并且单元中每个文件的修改时间都早于保留截止时间，才允许删除。任一分卷缺失、文件未过期或清单格式无效时跳过该单元并记录原因。

删除顺序固定为先删除全部分卷，最后删除外部清单。云存储不保证跨对象原子删除；若某个分卷删除失败，停止删除该单元并保留清单，记录已经删除和未删除的对象，供下一次重试。不能把部分删除报告为完整成功。

“上传后立即删本地包”对分卷模式删除完整中间 ZIP、全部分卷和外部清单；对单 ZIP 继续删除原来的单文件。

本机、网络共享、FTP 和五个云服务商分别执行同一套单元规则。云对象只允许在相同产品前缀和相同备份标识目录内分组和删除，不得删除其它产品或其它备份单元的文件。

**Key interfaces:**

- `BackupUnit` 或等价结构：由外部清单路径、备份标识、分卷路径和单元时间组成。
- `BackupUnitPurge.IsExpiredUnit()`：校验清单、文件齐全性和所有文件时间，返回可删除或不可删除原因。
- `BackupUnitPurge.DeleteLocalUnit()`：按分卷、清单、空目录的顺序删除，并返回部分失败信息。
- 本机、UNC、FTP 清理入口：先识别普通单 ZIP，再识别分卷单元，单 ZIP 保持原规则。
- 云对象列表接口：返回对象名称、大小和修改时间，并允许按产品前缀及备份标识分组。
- `ICloudRuntime` 或等价接口：提供单元级删除，由具体云适配器完成对象删除；任务层不直接依赖服务商协议。
- 立即删除入口：接受完整备份单元，而不只是单个 ZIP 路径。

**Acceptance criteria:**

- [ ] 普通单 ZIP 继续按自身修改时间和现有规则清理。
- [ ] 一个分卷单元只有在外部清单存在、全部分卷齐全且所有文件均超过保留时间时才删除。
- [ ] 单元中任一分卷未过期、缺失或无法读取时间时跳过整组，并记录具体原因。
- [ ] 外部清单格式不支持或声明的分卷与实际文件不一致时跳过整组。
- [ ] 删除顺序为先删全部分卷，最后删除外部清单。
- [ ] 分卷删除失败时停止该单元后续删除，保留外部清单并记录已删除和失败对象。
- [ ] “上传后立即删本地包”对分卷单元删除完整中间 ZIP、全部分卷和外部清单。
- [ ] 本机、UNC、FTP 都使用同一单元判断和删除顺序。
- [ ] 五个云适配器都按产品前缀和备份标识目录分组，不单独删除 `.manifest.json` 或孤立 `.zip`。
- [ ] 云服务商不支持原子删除时，错误结果包含部分删除事实，而不是报告全部成功。
- [ ] 不删除其它产品或同前缀下不同备份标识的对象。
- [ ] 测试覆盖整组过期、单文件未过期、缺卷、清单损坏、分卷删除失败和网络/云端部分删除。
- [ ] 旧单 ZIP 和现有清理配置保持兼容。

**Out of scope:**

- 分卷生成、清单格式、上传校验和逐文件补传；这些由前置工单提供。
- 手工恢复界面和数据库分卷恢复。
- 云端批量事务或跨提供商原子删除。
- 回收站、撤销删除、延迟删除队列或按分卷大小配额清理。
- 修改现有保留天数设置项。
- 真实云账号清理验收。
- 恢复当前工作树中无关的已删除测试或部署文件。
