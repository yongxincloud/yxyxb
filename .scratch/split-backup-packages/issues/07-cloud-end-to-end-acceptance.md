# 真实云账号端到端验收

Category: enhancement  
Status: ready-for-human  
Type: HITL

## Parent

[分卷备份包与运行统计](../spec.md)

## What to build

使用真实测试文件和真实云账号完成分卷备份、失败重试、远端校验、手工下载、目录恢复和整单元删除的验收。该工单需要人工提供测试账号或在无人值守环境能使用的测试凭据，并确认云控制台中的对象数量、大小和目录结构。

## Acceptance criteria

- [ ] 20 MiB 测试文件配合 8 MiB 上限生成多个分卷。
- [ ] 第二卷首次上传失败后，重试只补传未完成的文件和通道。
- [ ] 云控制台中的全部分卷和外部清单大小正确、目录属于同一备份单元。
- [ ] 下载全部分卷和清单到一个目录后，客户端恢复文件与源文件逐字节一致。
- [ ] 删除或修改一个分卷后恢复被拒绝。
- [ ] 自动删除只移除完整过期单元，不留下孤儿对象。
- [ ] MSSQL 或 MySQL 至少完成一种真实数据库实例的分卷与恢复验收。
- [ ] 验收记录注明云服务商、环境、对象数量、耗时和失败重试结果，不记录密钥。

## Agent Brief

**Category:** enhancement  
**Summary:** 使用真实云服务、真实文件和真实数据库完成分卷备份、重试、下载恢复和整单元保留的人工端到端验收。

**Why this is ready for a human:**

验收需要真实云账号、云控制台访问、手工下载对象、观察对象数量和目录结构，并至少使用一个真实 MSSQL 或 MySQL 实例。仓库没有可无人值守执行的真实生产链路测试入口，且凭据、外部账号状态和数据库环境不能由当前自动化任务安全控制。

**Current behavior:**

前置工单完成后，系统将具备分卷生成、逐文件上传校验、手工目录恢复、数据库分卷和整单元清理。生产云服务、真实数据库和人工下载流程尚未经过端到端验收。

仓库中存在本地配置和应用配置文件，但本工单不得读取、记录或提交其中的密钥。自动化测试只覆盖假通道和本地文件行为，不能证明真实服务商接口、权限、控制台显示或网络环境符合预期。

**Desired behavior:**

使用隔离测试数据和专用测试凭据，在一个真实云服务商上完成一次完整分卷文件备份。人为制造第二卷首次上传失败，确认重试只补传未完成的文件和通道。

在云控制台确认所有分卷和外部清单位于同一备份单元目录，对象数量、文件名和大小符合清单。全部手工下载到同一本地目录后，通过客户端恢复，逐字节比较恢复文件与源文件。

删除或修改一个已下载分卷，确认恢复被拒绝。将测试单元设为过期并执行清理，确认只删除完整单元，控制台没有孤儿分卷或清单。

至少选择一个真实 MSSQL 或 MySQL 实例，完成数据库分卷备份、手工下载、目录组装和数据库恢复。所有验证使用非生产数据，并在完成后清理测试对象和临时文件。

**Key interfaces:**

- 客户端设置与任务界面：配置 8 MiB 测试分卷上限并启用一个真实云通道。
- 文件备份任务：产生多个分卷、外部清单和可见的上传结果。
- 上传重试：在第二卷失败后继续任务，并在日志中显示只补传未完成项。
- 云控制台：人工核对备份单元目录、对象数量、文件名和大小。
- 手工文件系统目录：承载全部下载分卷和外部清单。
- 文件恢复界面：选择下载目录和恢复目录，显示校验或恢复结果。
- 数据库备份与恢复界面：使用真实测试实例完成同类验收。
- 自动删除配置与清理日志：人工核对完整单元删除和部分失败行为。

**Acceptance criteria:**

- [ ] 使用 20 MiB 测试文件和 8 MiB 上限生成多个分卷。
- [ ] 第二卷首次上传失败后，下一次执行只补传未完成文件和通道。
- [ ] 云控制台中全部分卷和外部清单位于同一备份单元，数量、文件名和大小与清单一致。
- [ ] 手工下载全部分卷和清单到一个目录后，客户端恢复成功。
- [ ] 恢复文件与原始文件逐字节一致。
- [ ] 删除或修改一个下载分卷后，恢复被拒绝并指出相应分卷。
- [ ] 自动删除只移除完整过期单元，云控制台没有孤儿分卷或清单。
- [ ] MSSQL 或 MySQL 至少一个真实测试数据库完成分卷备份、下载、组装和恢复。
- [ ] 失败、部分成功、重试和最终成功在日志中有可诊断记录。
- [ ] 验收记录包含云服务商、测试环境、对象数量、总大小、耗时和失败重试结果。
- [ ] 验收记录不包含 AccessKey、SecretKey、Token、数据库密码或其它密钥。
- [ ] 测试云对象、下载文件、恢复目录和数据库测试库在验收结束后清理，或明确记录保留原因。

**Out of scope:**

- 修复前置工单未提供的功能。
- 自动访问生产云账号或在自动化会话中读取本地密钥。
- 使用生产客户数据、生产数据库或不可恢复的测试数据。
- 对所有五个云服务商逐一验收；本工单只要求至少一个云服务商和至少一种数据库。
- 编写新的真实云集成测试框架。
- 修改 SMTP、授权、订单或设备限制。
- 恢复当前工作树中无关的已删除测试或部署文件。
