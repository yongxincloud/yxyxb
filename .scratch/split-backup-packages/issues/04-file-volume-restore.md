# 手动目录恢复文件分卷

Category: enhancement  
Status: ready-for-agent  
Type: AFK

## Parent

[分卷备份包与运行统计](../spec.md)

## What to build

用户从云空间手工下载全部分卷和清单后放入同一目录，在客户端选择该目录进行恢复。程序只允许一组备份标识，优先读取外部清单，缺失时读取内嵌清单；校验所有分卷后组装原 ZIP，并安全解压到新建的时间戳子目录。

## Acceptance criteria

- [ ] 恢复页支持选择分卷下载目录和恢复父目录。
- [ ] 缺少任一分卷时拒绝恢复并指出文件名。
- [ ] 分卷哈希不一致、重复序号或清单版本不支持时拒绝恢复。
- [ ] 外部清单缺失时可以使用内嵌清单恢复。
- [ ] 输出目录采用 `restore-yyyyMMdd-HHmmss`，冲突时追加序号。
- [ ] 已存在文件不会被覆盖。
- [ ] 绝对路径、`..` 和越过目标目录的 ZIP 条目录会被拒绝。
- [ ] 测试验证正常恢复、缺卷、损坏、清单回退和路径穿越。

## Agent Brief

**Category:** enhancement  
**Summary:** 让用户从手工下载目录选择一组分卷，校验并组装后恢复到新的时间戳目录。

**Current behavior:**

恢复页只提供 MSSQL 和 MySQL，没有文件恢复入口。数据库恢复的输入是一个单文件，不能选择目录。ZIP 解压逻辑只支持从单 ZIP 中提取第一个数据库文件，不支持恢复完整目录结构，也没有拒绝绝对路径、`..` 或越过目标目录的 ZIP 条目。

程序没有分卷扫描、外部清单回退、分卷组装或时间戳恢复目录能力，也不提供从云空间自动下载。

**Desired behavior:**

恢复页增加“文件”页签。用户选择分卷下载目录和恢复父目录，并可输入压缩密码。程序只接受一个目录作为分卷输入，扫描该目录中的外部清单和分卷。

目录只允许一组备份标识。若存在多个备份单元、缺失分卷、重复分卷序号、不支持清单版本、payload 长度不一致或哈希不一致，则拒绝恢复并指出具体原因。

程序优先读取外部清单；外部清单缺失时读取任一已下载分卷中的内嵌清单。校验通过后，按清单顺序把 payload 组装到临时完整 ZIP，再校验完整 ZIP 的 SHA-256。

完整 ZIP 通过校验后，在恢复父目录下创建新的 `restore-yyyyMMdd-HHmmss` 子目录。同名目录已存在时追加 `-01`、`-02`，不覆盖任何已有文件。若恢复失败，删除本次创建的空或半成品输出目录并保留原始下载文件。

解压必须拒绝绝对路径、包含 `..` 的路径和任何解析后超出恢复目标目录的条目。只允许在目标目录内部创建目录和文件。

**Key interfaces:**

- `PackageSplitter.ScanUnit()`：扫描输入目录，选择外部或内嵌清单，返回唯一备份单元并执行结构、长度和哈希校验。
- `PackageSplitter.Assemble()`：按清单顺序把 payload 组装到临时 ZIP，并校验完整 ZIP 的 SHA-256。
- `ZipPacker.ExtractAllSafe()`：完整提取 ZIP 目录结构，阻止路径穿越并输出已恢复文件数量与字节数。
- `FileRestoreService.Restore()`：协调扫描、组装、唯一时间戳目录创建、安全解压和失败清理。
- 恢复页“文件”页签：提供输入目录、输出父目录、密码、开始恢复和可读错误提示。
- 时间戳目录创建：接受父目录并返回不会与现有路径冲突的新目录。

**Acceptance criteria:**

- [ ] 恢复页提供“文件”页签，可分别选择分卷输入目录和恢复父目录。
- [ ] 输入目录缺失、不可读或不属于同一备份单元时拒绝恢复。
- [ ] 目录中存在多组备份标识时拒绝恢复并说明检测到多组。
- [ ] 缺少任一分卷时拒绝恢复并指出缺失文件名。
- [ ] 重复分卷序号、不支持清单版本、payload 总长度不一致或哈希不一致时拒绝恢复。
- [ ] 外部清单存在时优先使用；外部清单缺失时可以使用内嵌清单恢复。
- [ ] 组装后的完整 ZIP 通过 SHA-256 校验后才开始解压。
- [ ] 输出目录位于恢复父目录下，采用 `restore-yyyyMMdd-HHmmss`，冲突时追加序号。
- [ ] 恢复不会覆盖任何已有文件。
- [ ] 绝对路径、`..` 和解析后越过恢复目标目录的 ZIP 条目会被拒绝。
- [ ] 恢复成功返回输出目录、恢复文件数和恢复字节数。
- [ ] 恢复失败时清理本次创建的空或半成品输出目录，不删除原始分卷和清单。
- [ ] 文件级测试覆盖正常恢复、缺卷、哈希损坏、多组备份、清单回退和时间戳目录冲突。
- [ ] 安全解压测试覆盖路径穿越，并证明目标目录外没有文件被创建。

**Out of scope:**

- 客户端从任何云空间自动下载分卷。
- 分卷生成、配置界面和上传；这些由工单 02、03 提供。
- MSSQL/MySQL 分卷恢复和整单元自动删除。
- 标准 `.z01`/`.z02`/`.zip` 分卷格式和第三方解压工具兼容。
- 覆盖恢复、合并到已有目录或让用户逐文件处理冲突。
- 引入新的 WPF 自动化测试框架。
- 恢复当前工作树中无关的已删除测试或部署文件。
