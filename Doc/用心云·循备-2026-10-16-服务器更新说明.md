# 服务器更新包 · 2026-10-16

| 项 | 内容 |
| --- | --- |
| **包目录** | `release/2026-10-16-server-update/` |
| **说明** | 本文件与本次提交在同一仓库。升级时以该目录里的三个子目录为准。 |
| **耗时** | 约 15–25 分钟（停服 → 覆盖 → 启动 → 抽查） |

## 1. 本包里有什么

| 子目录 | 用途 | 拷到哪里 |
| --- | --- | --- |
| `api/` | 网站接口（ASP.NET Core 8） | Linux：`/opt/yxyxb/api`；Windows：`C:\yxyxb\api` |
| `web/` | 营销站 + 门户 + 厂商后台 | Linux：`/opt/yxyxb/web`；Windows：`C:\yxyxb\web` |
| `desktop/` | Windows 客户端 + 引擎（`YxyXb.Client.exe` 与 `YxyXb.Engine.exe` 同目录） | 下载站，或发给用户解压覆盖 |

**本包不包含：** 数据库文件、`appsettings.Local.json`、支付宝密钥、百度密钥。

## 2. 本版变化

1. 门户「我的设备」可写备注。客户端登录或启动校验时，把本机设置里的「客户标识」写入这条备注。电脑名、MAC、Windows 用户仍走原来的显示名。
2. 厂商「客户」增加「定制版」。人数按这个客户单独填写，范围 1–9999，对应允许登录的设备台数。网站购买页仍只有个人版、标准版、专业版。
3. 厂商侧边栏增加「设备查询」，可按邮箱、姓名、客户号、设备名或备注查看设备和备注。
4. 厂商登录增加邮箱验证码，以及邮箱找回密码。管理员需先在后台绑定邮箱。
5. 新建文件任务、SQL Server 任务、MySQL 任务的重计时默认 30 分钟。自动删除（本机、网络、FTP、七牛、百度）默认 10 天。已经保存过的旧任务和旧天数不会被改写。
6. 首次启动会给已有库补列：`AccountDevices.Note`、`SubscriptionAuths.DeviceLimit`，并写入产品 `CUSTOM`（定制版）。

## 3. 更新前必做

1. **备份数据库**
   - Linux：`/var/lib/yxyxb/yxyxb-api.db`（及 `-wal` / `-shm` 若有）
   - Windows：`C:\yxyxb\data\yxyxb-api.db`
2. **备份** `appsettings.json` 和 `appsettings.Local.json`。
3. 确认服务器已装 **ASP.NET Core 8 运行时**。

## 4. Linux 更新步骤

```bash
sudo systemctl stop yxyxb-api
sudo rsync -a --delete ./api/ /opt/yxyxb/api/
sudo rsync -a --delete ./web/ /opt/yxyxb/web/
# 把备份的 appsettings.json / appsettings.Local.json 拷回 /opt/yxyxb/api/
# ConnectionStrings.Web 保持绝对路径，例如：
# "Web": "Data Source=/var/lib/yxyxb/yxyxb-api.db"
sudo chown -R www-data:www-data /opt/yxyxb/api /opt/yxyxb/web /var/lib/yxyxb
sudo systemctl start yxyxb-api
sudo systemctl status yxyxb-api --no-pager
curl -s http://127.0.0.1:5080/api/health
curl -s http://127.0.0.1:5080/api/public/price
sudo nginx -t && sudo systemctl reload nginx
```

网页更新后保留站点上的 `web.config`（若 Windows IIS 使用）。Linux Nginx 配置不用这个包替换。

## 5. 配置覆盖规则

| 文件 | 更新时 |
| --- | --- |
| `api` 下程序文件 | **覆盖** |
| `web` 下静态文件 | **覆盖** |
| `appsettings.json` | **保留生产版** |
| `appsettings.Local.json` | **不要用本包替换** |
| `yxyxb-api.db` | **绝不覆盖**。启动后自动加列和定制版产品 |

本包里的 `api/appsettings.json` 是开发机模板。上线继续用备份的生产配置。

## 6. 客户端（download 站）

1. 将 `desktop/` 打成 zip（例如 `yxyxb.zip`）。目录内必须同时有 `YxyXb.Client.exe`、`YxyXb.Engine.exe` 和 `YxyXb.Client.exe.config`。
2. 上传到现网下载地址。
3. 用户解压覆盖安装目录。保留用户机上的 `data\`、`bak\`、`BaiduApp.json`。已安装「用心云·循备 Service」时，覆盖后在客户端首页停止再启动一次服务。

## 7. 更新后检查

- [ ] `/api/health` 正常
- [ ] `/api/public/price` 仍是个人版、标准版、专业版，没有定制版
- [ ] 厂商登录 → 客户：账号类型里有定制版，选中后可填人数
- [ ] 厂商 → 设备查询：能按邮箱看到设备名称和备注
- [ ] 门户「我的设备」可保存备注
- [ ] 新客户端启动后，设备备注出现本机「客户标识」

## 8. 回滚

1. 停接口
2. 用更新前备份的 `api/`、`web/` 盖回
3. 若要完整回滚数据库，用更新前的 `yxyxb-api.db`。只加了可空列和一条产品时，旧程序一般仍能打开新库
4. 启动接口
