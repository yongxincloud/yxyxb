## 1. 产品与范围

**用心云·循备** = Windows 桌面客户端 + 本机任务引擎。授权规则按第 2 节执行。**本期无公网网站**：登录与日志上报做占位，不部署、不验收公网。

客户端与引擎须能运行于：**Windows 7 SP1、Windows 10、Windows 11、Windows Server 2008 R2 / 2012 / 2016 / 2019 / 2022**（32 位与 64 位）。技术选型见开发计划第 1 节（.NET Framework 4.8，不用 .NET 8 做客户端）。

全部配置、调度、执行在客户端。网站不下发配置、不管设备、不管云备份。

2. 离线介质（扫本机 `.zip` 拷到已登记移动硬盘并隔离）

### 1.2 本期不做

- Oracle / 达梦 / PostgreSQL（页签可灰显）。MySQL 实例和任务已开通，备份调用 mysqldump
- 工具插件（侧栏已去掉）

- 文件包恢复向导（本期仅数据库恢复：MSSQL / MySQL）

- 网站侧任何配置管理

- Inno / MSI 安装包（本期只出 zip）

## 6. 离线介质（独立模块）

与备份任务代码互不调用，只复用文件枚举、长路径、占用文件跳过。只读第 7.1 节路径下的正式 `.zip`，不触发备份、不上传。无网、无网站必须能跑。网站接通后，无网或联网校验失败时离线介质仍执行。本期不因试用到期停跑。不参与「立即删本地」判定。

术语：挂载 / 隔离。界面不得写「物理断开」。

### 6.1 登记

身份 = 磁盘序列号 + 磁盘签名 + 容量(GB)，禁止用盘符。卷用 GUID。只处理 `BusType ∈ {USB,1394,SD}` 且非系统/非启动盘。

根目录写 `.yxyxb\volume.marker.json`（序列号、登记设备、时间、客户标识）。他机标记 → 拒绝登记。未登记 / 标记缺失 / 序列号不符 → 拒绝写入。解绑若盘上有本产品数据须提示不再受管。每任务绑 1 块盘。

### 6.2 任务配置

| 项 | 默认 / 规则 |
| --- | --- |
| 扫描源 | 只读，= 7.1 路径 |
| 目标介质 | 已登记盘，必填 |
| 盘内目录 | `<盘根>\用心云循备\` |
| 周期 | 与文件任务相同，精确到分钟 |
| 任务开始 / 介质离线 | `HH:mm`–`HH:mm`，可跨零点。到任务开始时间后才检查介质并执行；到介质离线时间若仍在线则再离线 |
| 等待就位 | 默认 30 分钟，0=不等；轮询最小 1 分钟 |
| 超时未就位 | 默认跳过本次 |
| 版本数 M / 天数 D | 均默认 7，最小 1，先到先清 |
| 冲突 | 覆盖（默认）/ 跳过 |
| 完成后立即离线 | 默认勾选，等级默认 L2 卷离线。勾选则拷贝成功后立刻离线，不等介质离线时间 |
| 巡检哈希 | 可选 SHA-256，**默认关**；关则仍用大小+mtime |

保存：任务开始与介质离线不能相同；bak 不得在目标盘上；目标不能是系统盘。每任务仍只绑 1 块盘，不做轮换池。

### 6.3 执行

到任务开始时间且周期已到 → 检查介质是否在线：已在线则直接执行；未在线则先挂载再执行 → 按序列号匹配 → 校验标记 → 扫 bak 全部 `.zip`（忽略 `.yxypart`）→ 按「相对路径+大小+mtime」跳过或复制 → 写版本记录 → 按 D/M 清理 → 若勾选完成后立即离线则马上离线，不等介质离线时间。

不打开资源管理器。没有能打开的盘符则本次不写入。

未接入则按轮询等到介质离线时间或等待上限。勾选完成后立即离线时，本次拷贝一成功就按所选级别离线，同一时段内不再自动挂回。未勾选则盘符留到介质离线时间。到介质离线时间再检查：仍在线则再离线；已不在线则不再动。未完成则不因离线时间去隔离一次未开始的拷贝，下一次任务开始再跑。同一盘串行。

手点「在线/离线」：有可用盘符则卷离线并去掉盘符；没有可用盘符则卷上线再挂盘符，目录能打开才算成功。手点会提示，不打开资源管理器。挂载与离线由服务在本机完成，不调用 PowerShell 或 `mountvol`。

盘上结构：

```text
<盘>\用心云循备\
  files\<相对 bak 路径>\*.zip
  versions\<yyyyMMdd-HHmmss>.json
  .yxyxb\volume.marker.json
```

先算应保留版本（最近 M 个且未过 D 天），再删集合外版本及其独占包。仍被引用的包不删。空跑（bak 无 zip）复制数 0，不算失败。

落盘顺序：关句柄 → FlushFileBuffers → LOCK+DISMOUNT 卷 → 写版本记录 → 记本机结果 → 若勾选完成后立即离线则马上离线。前几步任一步失败则不离线并告警。写入用 `*.yxypart` 再改名。到介质离线时间若介质仍在线，再离线一次。

下次挂载先巡检再写入；与最近版本不一致则标「疑似篡改」，暂停清理，等人确认。默认同「相对路径+大小+mtime」。任务勾选「巡检哈希」后，版本记录额外写 SHA-256，巡检按哈希比对；未勾选不算哈希、不因缺哈希报篡改。

### 6.4 隔离

| 等级 | 效果 | 说明 |
| --- | --- | --- |
| L1 | 去盘符 | 最弱。卷仍可按卷路径打开 |
| L2 | 卷离线 | **默认**。去掉盘符并拒绝读写。下次任务开始或点「在线」可再挂回。按钮「在线/离线」走这一档 |
| L3 | 整盘离线 | 可选。部分 U 盘不支持，或离线后程序挂不回 |
| L4 | PnP 弹出 | 可选。盘从系统消失，程序不能自己挂回 |

卷离线后，卷名仍可能出现在系统列表中，但读写被拒绝。这不是把磁盘从电脑上移除。会按卷扫描的程序仍可能看到卷名。整盘离线不作为默认，也不作为「在线/离线」按钮的动作。

拒绝隔离（须记安全事件）：非 USB/1394/SD、系统/启动盘、承载 bak/程序/配置的卷、未登记或序列号不符。占用时重试 3 次（隔 10 秒）。

## 7. 设置

### 7.1 备份存储

默认路径 = `<程序安装目录>\bak`。例：程序在 `D:\yxyxb` → `D:\yxyxb\bak`。不写死 `C:\bak`。压缩：zip。等级 0–9，默认 5。

压缩密码可空。填写后只加密**之后新打包**的文件备份与库备份 zip：包内文件名仍可见，解压或打开内部文件时要密码。已生成的旧 zip 不补加密。介质拷贝只复制已有 zip，不会按密码重打包。密码不回显、不进日志。

### 7.2 命名

目录和文件名由「备份命名」勾选决定，只影响之后执行的任务。扩展名固定 `.zip`。文件名至少勾选一项。

目录可选：客户标识、备份类型（文件备份 / 库备份）、实例名（仅数据库）、任务名。文件名可选：客户标识、任务名、时间、库名（仅数据库）。默认勾选除「实例名」外的全部项。

文件备份示例：`<bak>\客户标识\文件备份\任务名\客户标识_任务名_时间.zip`。库备份示例：`<bak>\客户标识\库备份\任务名\客户标识_任务名_库名_时间.zip`。客户标识取综合设置，留空则为「用心云循备」。

### 7.3 网络 / FTP / EMAIL（本期必须做通）

本期不是占位：设置页能配、能测；任务勾选后引擎能传 UNC、能传 FTP、能发邮件。任一项已启用且失败 → 任务失败，且不触发立即删本地。

| 项 | 本期必须 |
| --- | --- |
| 网络传输（UNC） | 凭据加密、连接测试、把当次 `.zip` 拷到指定共享路径 |
| FTP | 凭据加密、连接测试、上传当次 `.zip` |
| EMAIL | 收件、SMTP、测试发送；邮件标题、内容、结尾可设置，支持 `{任务}` `{结果}` `{时间}` `{详情}`。设置页总开关「任务执行后发送邮件」加条件失败/成功/所有；任务须勾完成后发邮件。不含密码/密钥 |

源路径选 UNC / FTP（第 4 节）同样本期做通：能列目录、能打 zip。

### 7.4 云备份（独立一级菜单，不在本设置页填密钥）

云凭据与连接测试只在左侧「云备份」菜单。设置页的自动删除只勾「删哪个已实现的云」。

独立菜单只做服务商配置，不产生备份任务。

| 服务商 | 本期 | 最低字段 |
| --- | --- | --- |
| 七牛云 | 实现：保存、测试、分片上传、限速、按天删对象。**客户自填**自己的空间/AK/SK，产品不提供统一空间 | 空间名、AccessKey、SecretKey、区域、上行限速、下行限速 |
| 腾讯云 | 可见、禁用，提示「后续开通」 | 预留：地域、存储桶、SecretId、SecretKey |
| 天翼云 | 可见、禁用，提示「后续开通」 | 预留：地域、存储桶、访问密钥 |

- 引擎只依赖 `ICloudStorage`（测试、上传、限速、按前缀/时间删除）。任务勾选「云上传」时传服务商类型，不写死七牛类名。
- 七牛上传按 **4MB** 分片，同时 **2** 路，避免一次占满主机带宽。上传凭证覆盖大文件所需时间。
- 云备份页可设 **上行、下行**，单位 KB/s，与密钥一起保存，引擎自动执行共用。填 **0** 表示该方向不限速。上行限制云 / FTP / 共享上传；下行限制 FTP 源下载。并行默认 1（可填 1–2）。
- 密钥加密、界面脱敏、日志禁止明文。
- 上传失败则任务失败，且不触发立即删本地。
- 网站不配置任何云。

### 7.5 自动删除（每天默认 00:30）

可分别勾选并填天数（默认 7）：本机、网络、FTP、七牛云。腾讯云/天翼云在实现前无删除项。

- 本机：按文件时间删 bak 里过期的文件备份与 MSSQL `.zip`。
- 七牛云：只删本产品上传且过期的对象（前缀为客户标识加 `/`，未填时为 `用心云循备/`）；不勾则只传不删。每个对象的删除接口调用成功后写日志「删除调用成功：对象名」，当天汇总写「七牛删除调用成功，共 N 个。」失败告警，不写成功行。
- 立即删：只删当次本机包，且须网络/FTP/云上传/邮件（任务上已启用的）全成功；默认不勾；勾选须提示「离线可能拷不到本次包」。不立即删云端对象。
- 不删任务配置，不删离线盘（盘上由 6.3 的 D/M 清）。

### 7.6 综合

界面主题（明亮 / 深色 / Windows 11 / Mac，默认明亮）、开机启动、关窗到托盘、本机锁定密码、客户标识（默认「用心云循备」）。

本机锁定密码留空则不锁。填写后，下次启动或从托盘打开须输入密码；当前已经打开的窗口不受影响。已保存打开密码时，停止服务与卸载服务受第 8 节约束。

### 7.7 发布

## 8. 引擎与日志

- 自动执行依赖 Windows 服务 `YxyXbService`（显示名 `用心云·循备 Service`），启动类型自动，以 LocalSystem 运行。未安装/未启动首页持续告警。安装、启动、停止、卸载由首页按钮完成。
- 服务不接受系统里的停止（服务管理器、任务管理器“结束任务”、`sc stop`）。停止与卸载只能由首页按钮完成：软件先向服务发出短时授权（约 60 秒），再停止或卸载。已设置打开密码时，须先输入密码进入软件。计算机关机时仍允许系统停止服务。
- 在任务管理器“详细信息”里结束 `YxyXb.Engine.exe` 后，服务按失败恢复在约 1 秒内再启动。应用层不能把管理员的“结束进程”按钮变灰。
- 日志只读列表。离线介质行至少含：任务开始、介质离线、序列号、挂载、复制/跳过数与字节、删除版本与释放空间、耗时、隔离等级与结果。自动删除在七牛每个对象删除成功时写「删除调用成功：对象名」。不记介质凭据，不记邮件密码。
- 日志只留本机。网站上线后也不上报、不在网站查看这套列表。

## 9. 验收要点

1. 未登录、断网可做文件备份、离线介质、MSSQL、UNC/FTP/邮件。首页能显示试用剩余天数；本期到期只提示、不拦截。登录为占位。
2. 文件/MSSQL 按计划在 `<程序目录>\bak` 产出 `.zip`。文件任务与库任务也可立即执行。
3. 「云备份」可保存并测试七牛云；任务勾选云上传后能传到七牛。百度上传为 4MB 分片、可断点续传；并行默认 1。可设上行/下行（KB/s），0 表示该方向不限速。腾讯云/天翼云可见但不可用。自动删除勾选七牛后，过期对象逐个删除，每次调用成功记一条日志。
4. 任务开始后已登记盘在位：已在线则直接拷贝，未在线则先挂载 → 拷新包 → 清理 → 默认立刻 L2 卷离线，资源管理器无盘符。到介质离线时间若仍在线，再离线一次。程序不自动打开资源管理器。
5. 本机无新 zip 时离线复制数为 0。
6. 未登记/错盘/系统盘：不写入；非法隔离记安全事件。
7. 中断后无半成品正式文件，下次任务开始可续。
8. 立即删不参与离线判定；自动删除不删盘上文件、不删任务。
9. 本期无公网站：登录占位、无日志上报。下期做授权、试用订单（第 1 次 0.1 元、第 2 次 0.5 元，各 30 天，走支付）、续费从原到期日顺延、佣金轧差和客户可选开票，以《用心云·循备-后台系统开发需求文档》为准。备份日志仍只留本机。设备数按网站授权档位限制。离线介质无网仍可执行。
10. 系统与任务管理器不能直接停止服务；进入软件后首页可以停止和卸载。已设打开密码时须先输入密码。进程被结束后约 1 秒内服务再拉起。
11. 压缩密码只作用于之后新打的 zip。旧包不补加密。介质任务只拷已有 zip。

## 10. 本期已收口

1. 发布用 zip，不做 Inno / MSI。
2. 离线不做多盘轮换池。
3. 巡检默认大小+mtime；任务可勾选 SHA-256。
4. 隔离默认 L2 卷离线。L3 / L4 仍可选，不作为默认，也不作为「在线/离线」按钮。
5. 勾选完成后立即离线时，介质拷贝成功后立即离线，不等介质离线时间。到介质离线时间若介质仍在线，再执行一次离线。
6. 七牛/百度分片上传（百度 4MB），并可设置上行/下行限速。
7. 停止 / 卸载服务只能从已进入的客户端发起。任务管理器结束进程后，服务约 1 秒内再启动。
