# 服务器更新包 · 2026-10-07

| 项 | 内容 |
| --- | --- |
| **提交** | `1f5daf0`（及此前已合入的三档版本相关提交） |
| **包目录** | 本目录 `release/2026-10-07-server-update/` |
| **耗时** | 约 15–25 分钟（停服 → 覆盖 → 启动 → 抽查） |

## 1. 本包里有什么

| 子目录 | 用途 | 拷到哪里 |
| --- | --- | --- |
| `api/` | 网站接口（ASP.NET Core 8） | Linux：`/opt/yxyxb/api`；Windows：`C:\yxyxb\api` |
| `web/` | 营销站 + 门户 + 厂商后台前端 | Linux：`/opt/yxyxb/web`；Windows：`C:\yxyxb\web` |
| `desktop/` | Windows 客户端 + **引擎服务**（`YxyXb.Client.exe` 与 `YxyXb.Engine.exe` 同目录） | 下载服务器目录，或发给用户解压覆盖 |

**本包不包含：** 数据库文件、`appsettings.Local.json`、支付宝密钥、百度密钥。

## 2. 本版服务器侧变化（摘要）

1. 三档产品与设备上限（个人/标准/专业）
2. 公开价目 `GET /api/public/price` → `plans[]`
3. 门户「我的设备」、厂商改客户账号类型（写操作日志）
4. 营销首页居中；申请账号页左右分栏
5. 客户端登录上报设备显示名；登录/设备接口带版本与 `maxDevices`

客户端另有「恢复（库）」「我的设备」页，随 `desktop/` 下发，**不装在网站服务器上**。

## 3. 更新前必做

1. **备份数据库**  
   - Linux：`/var/lib/yxyxb/yxy-api.db`（及 `-wal`/`-shm` 若有）  
   - Windows：`C:\yxyxb\data\yxy-api.db`
2. **备份当前 `appsettings.json` / `appsettings.Local.json`**（支付、邮件、库路径别丢）
3. 确认服务器已装 **ASP.NET Core 8 运行时**（Linux 用 `aspnetcore-runtime-8.0`）

## 4. Linux 更新步骤

```bash
# 1) 停接口
sudo systemctl stop yxyxb-api

# 2) 覆盖程序（不要删库目录）
sudo rsync -a --delete ./api/ /opt/yxyxb/api/
sudo rsync -a --delete ./web/ /opt/yxyxb/web/

# 3) 还原生产配置（若 rsync 覆盖了配置）
# 把备份的 appsettings.json / appsettings.Local.json 拷回 /opt/yxyxb/api/
# ConnectionStrings.Web 保持绝对路径，例如：
# "Web": "Data Source=/var/lib/yxyxb/yxy-api.db"

# 4) 权限
sudo chown -R www-data:www-data /opt/yxyxb/api /opt/yxyxb/web /var/lib/yxyxb

# 5) 启动
sudo systemctl start yxyxb-api
sudo systemctl status yxyxb-api --no-pager

# 6) 抽查
curl -s http://127.0.0.1:5080/api/health
curl -s http://127.0.0.1:5080/api/public/price
sudo nginx -t && sudo systemctl reload nginx
```

浏览器无痕打开官网首页：应看到三列版本与设备数；登录门户看「我的设备」。

## 5. Windows 服务器更新步骤

管理员 PowerShell：

```powershell
sc.exe stop YxyApi
# 等几秒确认已停

robocopy .\api C:\yxyxb\api /MIR
robocopy .\web C:\yxyxb\web /MIR

# 还原 C:\yxyxb\api\appsettings.json（及 Local），保证：
# "Web": "Data Source=C:\\yxy\\data\\yxy-api.db"
# 不要覆盖 C:\yxyxb\data

sc.exe start YxyApi
Invoke-WebRequest -UseBasicParsing http://127.0.0.1:5080/api/health
Invoke-WebRequest -UseBasicParsing http://127.0.0.1:5080/api/public/price
```

IIS 站点根目录若指向 `C:\yxyxb\web`，一般只需覆盖 web；若用物理路径别名，改对应目录。

## 6. 配置覆盖规则（重要）

| 文件 | 更新时 |
| --- | --- |
| `api` 下 DLL / `YxyXb.Api.dll` 等 | **覆盖** |
| `web` 下全部静态文件 | **覆盖**（可先清空再拷） |
| `appsettings.json` | **保留生产版**；仅当结构变更时手工合并 |
| `appsettings.Local.json` | **永不被本包替换**（本包不含） |
| `yxy-api.db` | **绝不覆盖**；首次启动会自动加表/种子 |

本包里的 `api/appsettings.json` 只是开发机模板，**上线请用你备份的生产配置**。

## 7. 客户端（download 站）更新

1. 将 `desktop/` 打成 zip（例如 `yxyxb.zip`）。目录内须同时有 **`YxyXb.Client.exe`** 与 **`YxyXb.Engine.exe`**（及对应 `.config`）。
2. 上传到现网下载地址（手册中的 `download.yongxinyun.com/...`）。
3. 用户解压覆盖安装目录即可；保留用户机上的 `data\`、`bak\`、`BaiduApp.json`。若本机已安装「用心云·循备 Service」，覆盖后建议在客户端首页 **停止 → 启动** 一次服务。
4. 本机联调：`data\site.url` 写 `https://backup.yongxincloud.cn`（或测试 API 地址），无尾斜杠。

## 8. 更新后检查清单

- [ ] `/api/health` 返回正常  
- [ ] `/api/public/price` 返回三档 `plans`（含 `maxDevices`）  
- [ ] 首页三列价格可见  
- [ ] 厂商登录 → 客户 → 可改账号类型；操作日志有 `edition`  
- [ ] 门户「我的设备」可打开（未登录应提示登录，勿误显示空列表为唯一信息）  
- [ ] 旧客户端仍能登录；新客户端可见版本与设备列表  

## 9. 回滚

1. 停接口  
2. 用更新前备份的 `api/`、`web/` 整目录盖回  
3. 数据库用更新前的 `yxy-api.db` 备份还原（若已跑过迁移且要完整回滚）  
4. 启动接口
