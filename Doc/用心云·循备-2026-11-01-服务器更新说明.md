## 1. 本包里有什么

| 子目录 | 用途 | 拷到哪里 |
| --- | --- | --- |
| `api/` | 网站接口（ASP.NET Core 8） | `/opt/yxyxb/api` |
| `web/` | 营销站 + 门户 + 厂商后台前端 | `/opt/yxyxb/web` |
| `desktop/` | 客户端 1.1.0 安装包 `yxyxb.zip` 与 `version.json` | 下载服务器目录 `download.yongxinyun.com/yxyxb/` |

**本包不包含：** 数据库文件、`appsettings.Local.json`、支付宝密钥。包内 `api/appsettings.json` 是开发机模板。

## 3. 更新前必做

1. **备份数据库**：`/var/lib/yxyxb/yxyxb-api.db`（及 `-wal` / `-shm` 若有）
2. **备份当前 `appsettings.json` / `appsettings.Local.json`**
3. 上传更新包到服务器：

   ```powershell
   scp -r release\2026-11-01-server-update root@49.234.14.240:/tmp/yxyxb-update
   ```

## 4. ⚠️ 配置警告（本次特别注意）

包内 `api/appsettings.json` 是开发模板，**且带 `"ResetPassword": true`**。
若用它覆盖生产配置并重启，**admin 密码会被重置为开发弱密码 `Admin@yxxt123`**。
rsync 之后必须按第 5 节还原生产配置，确认无误再启动。

## 5. Linux 更新步骤

```bash
# 1) 停接口
sudo systemctl stop yxyxb-api

# 2) 覆盖程序（不要删库目录 /var/lib/yxyxb）
sudo rsync -a --delete /tmp/yxyxb-update/api/ /opt/yxyxb/api/
sudo rsync -a --delete /tmp/yxyxb-update/web/ /opt/yxyxb/web/

# 3) 还原生产配置（上一步覆盖了 appsettings.json，必须还原）
sudo cp 你的备份/appsettings.json /opt/yxyxb/api/appsettings.json
# appsettings.Local.json 若被删也一并还原

# 4) 权限
sudo chown -R www-data:www-data /opt/yxyxb/api /opt/yxyxb/web

# 5) 启动
sudo systemctl start yxyxb-api
sudo systemctl status yxyxb-api --no-pager

# 6) 抽查
curl -s http://127.0.0.1:5080/api/health
curl -s http://127.0.0.1:5080/api/public/price
```

浏览器无痕打开官网首页：应看到「适配的云存储」版块（五家云卡片）。

## 6. 客户端（download 站）更新

**顺序不能反：先传 zip，再覆盖 version.json**，否则旧客户端会下载到校验不符的包。

1. 上传 `desktop/yxyxb.zip` 到 `download.yongxinyun.com/yxyxb/yxyxb.zip`
2. 上传 `desktop/version.json` 覆盖 `download.yongxinyun.com/yxyxb/version.json`
3. 本包 sha256（version.json 内已写，核对用）：

   ```text
   4ebf9eeba36cfec65b1da56a52f5a914164ed2165aacee033029921d0de1bde6
   ```

4. 客户端有网且空闲时约 2 分钟后自动检查更新；也可在用户机上解压覆盖，保留 `data\`、`bak\`、已有 `BaiduApp.json`，覆盖后在首页 **停止 → 启动** 一次服务。

1. 停接口
2. 用更新前备份的 `api/`、`web/` 整目录盖回
3. 数据库用更新前的 `yxyxb-api.db` 备份还原（若已跑过迁移且要完整回滚）
4. 下载站把旧 zip 和旧 `version.json` 盖回
5. 启动接口
