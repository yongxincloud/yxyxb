# 用心云备份 操作手册

本文按当前程序的按钮和实际动作编写。恢复、工具本期不能用。左下角「官网」用浏览器打开 https://backup.yongxincloud.cn 。登录网站账号前，要在程序旁的 `data\site.url` 写一行网站地址，末尾不要斜杠；不写时登录会连 `http://127.0.0.1:5080`。电脑没有网络时，已保存的离线介质任务到点仍会执行。试用订单、续费顺延、佣金和开票见《用心云备份-后台系统开发需求文档》。

## 近期更新

1. **介质任务时间。** 「窗口开始 / 窗口结束」改为 **任务开始时间**、**介质离线时间**。到开始时间先检查介质是否在线：已在线就执行，未在线则先挂载再执行。勾选「完成后立即离线」时，拷贝一结束就离线。到介质离线时间若仍在线，再离线一次。
2. **文件任务立即执行。** **任务 → 文件** 点选一行后可 **立即执行**，不必等到下次计划时间。结果看弹窗和 **日志 → 文件备份**。
3. **邮件可设置。** **设置 → EMAIL** 可改邮件标题、邮件内容、邮件结尾。可用 `{任务}`、`{结果}`、`{时间}`、`{详情}`。标题或内容留空时用默认句式；结尾留空则不附加。
4. **七牛删除成功要记日志。** 自动删除里，每个过期对象的删除接口调用成功后，**日志 → 自动删除** 会写「删除调用成功：」加对象名，并有一行「七牛删除调用成功，共 N 个。」失败不写成功行。
5. **官网。** 左下角 **官网** 打开 https://backup.yongxincloud.cn 。
6. **用心云主题。** **设置 → 综合设置** 的界面主题增加 **用心云**。侧栏为墨色，按钮为正红。默认仍是明亮。
7. **备份目录默认值。** 新安装或仍使用程序目录下 `bak` 的，打开后改为 `D:\yongxinyunbackup\bak`。已经改成别的路径的不会动。
8. **登录后的称呼。** 网站「账号信息」里没填姓名、昵称、公司名称时，客户端显示邮箱。填过以后显示「公司名称 姓名（昵称）」。授权剩余超过 30 天只显示可用至哪一天，不显示剩余天数，也不显示下次联网校验间隔。剩余 30 天及以内仍显示剩余天数。重新登录后生效。
9. **MySQL。** **实例 → MySQL** 可添加实例并测试连接。**任务 → MySQL** 可添加任务并立即执行。系统库 `information_schema`、`mysql`、`performance_schema`、`sys` 不备份。需要 `mysqldump.exe`（已安装的 MySQL 客户端，或放在程序目录）。zip 在备份目录的「库备份」下。
10. **网站门户。** 购买只走支付宝，没有微信。侧栏是「账号信息」，可填姓名、昵称、公司、手机和开票资料，并进入找回密码；侧栏有退出。开票只勾选已支付、金额大于 0、尚未开票的记录。续费 / 订单里，未支付、已关闭、已退款的记录可删除；已支付的要先退款。营业执照用文件选择框，选 JPG 或 PNG。

## 1. 先让引擎跑起来

左侧点 **首页**。

1. 看「引擎」。未安装时点 **安装服务**，再点 **启动服务**。
2. 显示运行中之后，到点的任务才会执行。客户端关掉不影响服务。
3. 安装或启动失败时，用管理员身份重新打开客户端再试。
4. **停止服务**、**卸载服务** 只在本软件里做。任务管理器里的“结束任务”停不掉这项服务。若在“详细信息”里结束 `Yxy.Engine.exe`，大约 1 秒后服务会自己再启动。填了打开密码时，要先输入密码进入软件，再点首页的停止或卸载。

主窗口没有系统标题栏。左下角「登录」旁是 **退出**。点开后可选 **最小化**、**退出程序**、**取消**。选最小化后，任务栏不留按钮，右下角通知区域出现图标，双击可打开。

关闭窗口时，若在 **设置 → 综合设置** 勾了关闭到托盘，程序缩到右下角。托盘图标双击或点「打开」可回到窗口，点「退出」才真正退出。

## 2. 日常要用的顺序

做离线介质备份时，按这个顺序：

1. 在 **设置 → 备份存储** 确认备份目录和压缩密码，点保存。
2. 在 **任务** 里添加文件备份（或库备份），让数据先打成 zip，落到备份目录。
3. 插入 U 盘或移动硬盘，在 **离线介质 → 登记介质** 登记这块盘。
4. 在 **离线介质 → 介质任务** 添加任务，指定扫描源、任务开始时间、介质离线时间和隔离级别。
5. 到任务开始时间后，服务先看介质是否在线。已在线就拷贝；未在线则先挂载再拷贝。拷贝完成后马上离线。到介质离线时间若仍在线，再离线一次。
6. 到 **日志 → 离线介质** 看结果。

## 3. 设置

左侧点 **设置**。改完必须点该页的保存。

### 备份存储

- **备份目录**：文件备份和库备份的 zip 放在这里。介质任务默认也从这里往盘上拷。默认是 `D:\yongxinyunbackup\bak`。
- **压缩等级**：0 到 9，默认 5。0 几乎不压缩，9 更小更慢。
- **压缩密码**：可空。留空则 zip 不加密。填写后，**之后新打出来的** zip 会要密码才能解压。密码不会写进日志。
- 打开 zip 仍能看到里面的文件名。双击里面的文件或解压时，系统才会要密码。
- 已经生成的旧 zip 不会补上密码。改密码后要再执行一次备份。

### 备份命名

勾选要出现在目录名和文件名里的部分。目录和文件名都可以勾选 **客户标识**。保存后看预览。只影响之后执行的任务。

### 网络传输、FTP、EMAIL

把备份再送到共享目录、FTP 或邮箱时才填。EMAIL 可改邮件标题、邮件内容和邮件结尾。可用 `{任务}`、`{结果}`、`{时间}`、`{详情}`。填完点保存，再用该页的测试。

### 自动删除

按保留天数删过期 zip。勾选要清理的位置，填天数和每天清理时间，然后保存。勾了七牛时，每个对象删除成功都会在 **日志 → 自动删除** 记「删除调用成功：对象名」。

### 综合设置

- **界面主题**：明亮（默认）、深色、Windows 11、Mac、用心云。保存后立即切换。用心云的侧栏为墨色 `#1C1214`，按钮为正红 `#DC0606`。
- **客户标识**：出现在勾选了该项的备份目录名和文件名里。留空保存后为「用心云备份」。
- **开机启动**、**关闭到托盘**。
- **本机锁定密码**：留空则不锁。保存后，下次启动或从托盘打开时要输入。当前已经打开的窗口不受影响。

## 4. 文件备份和库备份

左侧点 **任务**。

### 文件

点 **添加**。名称、源（本地 / UNC / FTP）、文件夹、周期、下次执行时间填好后保存。点选该行可 **立即执行**。结果看弹窗，也看 **日志 → 文件备份**。到点后服务也会把文件打成 zip，放到备份目录。

### MSSQL

1. 先到左侧 **实例**，添加 SQL Server 实例并测试连接。
2. 回到 **任务 → MSSQL**，点 **添加**。
3. 可点 **立即执行**。结果看弹窗，也看 **日志 → 数据库备份**。
4. zip 在备份目录的「库备份」下。离线介质任务到任务开始时间后能扫到这些 zip。

### MySQL

1. 先到左侧 **实例 → MySQL**，填写服务器、端口（默认 3306）、用户名、密码，点 **测试连接**。
2. 回到 **任务 → MySQL**，点 **添加**。范围可选全部用户库，或填写指定库名（逗号分隔）。
3. 可点 **立即执行**。结果看弹窗，也看 **日志 → 数据库备份**。
4. 备份调用 `mysqldump.exe`。本机已安装 MySQL 客户端时一般能找到；找不到时，把 `mysqldump.exe` 放到程序同一目录。
5. zip 在备份目录的「库备份」下。

Oracle、达梦、PostgreSQL 本期不能用。

## 5. 登记离线介质

左侧点 **离线介质 → 登记介质**。只接受 USB、1394、SD（含 USB 移动硬盘）。系统盘不能登记。

1. 插入磁盘，点 **刷新接入盘**。
2. 在上方列表选中该盘，点 **登记选中**。身份是「序列号 / 签名 / 容量」。
3. 下方「已登记」里点选这一行，再用 **在线/离线**。

**在线/离线** 的动作：

| 当前状态 | 点击后 |
| --- | --- |
| 有盘符且能打开 | 卷离线，并去掉盘符。提示「已卷离线」。资源管理器里不再显示。 |
| 没有能打开的盘符 | 按登记时的卷先上线，再挂盘符。目录能打开才算成功。 |

手点会弹出「离线介质」提示框。程序不会再自动打开资源管理器。

卷离线之后，卷的名字仍可能出现在系统列表里，但读写会被拒绝，直到再次在线。这不是把磁盘从电脑上拔掉。会按卷扫描的程序，仍可能看到这个卷名。

**解绑登记** 只取消软件对这块盘的管理，不删除盘里的文件。

**标记疑似篡改** 后，介质任务会暂停清理旧版本。确认盘没有问题后，点 **确认盘完好**。

## 6. 介质任务

左侧点 **离线介质 → 介质任务**。

点 **添加**，常用项：

| 项 | 怎么填 |
| --- | --- |
| 名称 | 自己认识的任务名 |
| 扫描源 | 留空则用设置里的备份目录。也可点「选择」指定文件夹 |
| 目标介质 | 选已登记的盘 |
| 盘内目录 | 默认「用心云备份」 |
| 任务开始时间 | 到这个时间后才检查介质。已在线就执行；未在线则先挂载，挂好再执行。例如 22:00 |
| 介质离线时间 | 到这个时间再查一次。介质仍在线就再执行离线。例如 23:00 |
| 等待就位(分) | 任务开始后盘还没插上时，最多再等多久。到介质离线时间仍没有盘，本次跳过 |
| 保留版本 M、保留天数 D | 盘上保留多少份、多少天 |
| 冲突 | 覆盖，或跳过已有文件 |
| 周期、间隔、下次执行 | 决定什么时候算到点 |
| 完成后立即离线 | 默认勾选。备份成功后立刻离线，不等介质离线时间 |
| 隔离级别 | 默认 **L2 卷离线**。与按钮「在线/离线」同一档，可以再自动挂回 |

隔离级别不要随便改高：

- **L1 去盘符**：只去掉盘符，卷仍可被按卷路径打开。
- **L2 卷离线**：推荐。去掉盘符，并拒绝读写。下次任务开始或点「在线」时，程序会再挂回来。
- **L3 整盘离线**：部分 U 盘不支持，或离线后挂不回来。
- **L4 PnP 弹出**：盘从系统消失，程序不能自己把它插回来。

保存并保持 **启用**。

### 到点以后程序做什么

1. 到任务开始时间，且到了下次执行时间：介质已在线就直接拷贝；未在线则先挂上盘符再拷贝。没有提示框，也不打开资源管理器。
2. 把扫描源里的 zip 拷到盘内目录。
3. 勾了「完成后立即离线」时，这次拷贝一结束就按所选级别离线，不等介质离线时间。同一时段内不会再自动挂上。
4. 没勾「完成后立即离线」时，盘符留到介质离线时间。
5. 到介质离线时间再检查：介质仍在线就再离线一次；已经不在线则不再动。
6. 盘没插上时，在「等待就位」时间内继续等。超时或到介质离线时间仍没有盘，本次跳过。
7. 没有能打开的盘符时，本次不往盘里写文件。

点 **立即执行** 会马上拷贝。若勾了完成后立即离线，拷完同样离线。

日志里成功时应能看到「任务完成，已立即离线。」到介质离线时间若盘还在，会再写「介质仍在线，已再离线」。

## 7. 云备份

左侧 **云备份**。本期可用七牛。腾讯云、天翼云不能保存。填密钥后点保存，再测试连接。文件任务或库任务里勾了云备份时，zip 会再上传一份。

上传按 4MB 分片，同时 2 路。同一页可填上传下限和上限，单位 KB/s。上限 0 表示不限速。上限大于 0 时，总速度不超过上限。下限不能大于上限；上限为 0 时下限不生效。改完要点保存。

## 8. 看结果

左侧点 **日志**。

| 页 | 看什么 |
| --- | --- |
| 文件备份 | 文件任务是否打出 zip，是否写了「已用压缩密码」 |
| 数据库备份 | 库备份是否成功 |
| 离线介质 | 是否挂载、是否拷贝、是否「任务完成，已立即离线」 |
| 自动删除 | 过期包是否删掉。七牛每个对象删除成功会写「删除调用成功：对象名」 |

说明栏里的「成功 / 失败」为准。失败时先看说明，再看盘是否插上、服务是否在运行。

## 9. 使用时注意

1. 介质任务拷的是备份目录里的 zip，不会把 U 盘上的文件再压一次。
2. 压缩密码只保护新的 zip。手点「在线」不会给盘上已有文件加密码。
3. 卷离线不是杀毒，也不是把盘从系统里移除。
4. 任务开始后会检查介质是否在线，未在线则先挂载再拷贝。备份完成后会立即离线。到介质离线时间若仍在线，会再离线一次。手点「在线/离线」可以随时切换。
5. 若 Windows 弹出「需要格式化」，点取消。隔离不会格式化磁盘。

## 10. 网站客户门户

地址 https://backup.yongxincloud.cn 。登录后：

| 位置 | 能做 |
| --- | --- |
| 续费 / 订单 | 购买一年或试用，只走支付宝。已支付可退款。未支付、已关闭、已退款的记录可删除 |
| 账号信息 | 填写姓名、昵称、公司名称、手机号，以及开票抬头、税号、收票邮箱和营业执照图片。可进入找回密码 |

| 退出 | 侧栏底部退出登录 |

支付宝电脑网站支付和退款已接入。配置在服务器的 `appsettings.Local.json`（不进版本库）：APPID、应用私钥、支付宝公钥、通知地址 `https://backup.yongxincloud.cn/api/payments/alipay/notify`、回跳地址 `https://backup.yongxincloud.cn/orders`。
