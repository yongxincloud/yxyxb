# 用心云·循备 配置手册

密钥不进版本库、不进日志。本文只写字段和开放平台要对齐的项。正式地址：https://backup.yongxincloud.cn 。

官网 443 套件见《Linux部署手册》第 5 节。客户端用法见《操作手册》。

---

## 1. 支付宝（网站收款）

程序：`Yxy.Api`。文件：接口目录下的 `appsettings.Local.json`（Linux `/opt/yxy/api/`，Windows `C:\yxy\api\`）。仓库不提交这份文件。改完后重启接口（`systemctl restart yxy-api` 或 `sc.exe stop/start YxyApi`）。

开放平台：电脑网站支付，**公钥模式 RSA2**。不要用证书模式。

| 字段 | 填什么 |
| --- | --- |
| `AppId` | 支付宝应用 APPID |
| `SignType` | 固定 `RSA2` |
| `PrivateKey` | 应用私钥，PKCS8，无头尾、无换行 |
| `AlipayPublicKey` | 支付宝公钥（不是应用公钥），无头尾、无换行 |
| `Gateway` | `https://openapi.alipay.com/gateway.do` |
| `NotifyUrl` | `https://backup.yongxincloud.cn/api/payments/alipay/notify` |
| `ReturnUrl` | `https://backup.yongxincloud.cn/orders` |

模板（把 `替换` 换成真实值）：

```json
{
  "Alipay": {
    "AppId": "替换",
    "SignType": "RSA2",
    "PrivateKey": "替换",
    "AlipayPublicKey": "替换",
    "Gateway": "https://openapi.alipay.com/gateway.do",
    "NotifyUrl": "https://backup.yongxincloud.cn/api/payments/alipay/notify",
    "ReturnUrl": "https://backup.yongxincloud.cn/orders"
  }
}
```

开放平台还要勾：

1. 接口：电脑网站支付、统一收单交易退款。
2. 授权回调 / 应用网关：与上面 `NotifyUrl` 同域 HTTPS。
3. 异步通知必须公网可达。Nginx `/api/` 要转到本机 5080。
4. 没有这份配置或三项密钥为空时，购买页提示先配置异步通知地址。
5. 不接微信支付。没有备案域名和 HTTPS 时不要配这份文件。

## 2. 百度网盘（客户端上传）

网站不参与。客户不申请百度应用。产品共用一个开放平台应用，密钥打在安装包旁的 `BaiduApp.json`。

| 文件 | 位置 |
| --- | --- |
| 模板 | 仓库 `src/Yxy.Baidu/BaiduApp.example.json` |
| 正式 | `Yxy.Client.exe`、`Yxy.Engine.exe` **同一目录** 的 `BaiduApp.json` |
| 忽略 | `.gitignore` 已忽略 `BaiduApp.json` |

模板：

```json
{
  "AppKey": "替换",
  "AppSecret": "替换",
  "RedirectUri": "http://127.0.0.1:17890/baidu/",
  "AppFolderName": "用心云·循备"
}
```

| 字段 | 规则 |
| --- | --- |
| `AppKey` / `AppSecret` | 开放平台应用。缺文件或为空 → 提示「未配置百度应用」 |
| `RedirectUri` | 必须与开放平台授权回调 **完全一致**，含末尾 `/`。默认 `http://127.0.0.1:17890/baidu/` |
| `AppFolderName` | 必须与应用文件夹名一致。默认 `用心云循备`。网盘路径 `/apps/{AppFolderName}/…` |

开放平台：

1. 授权回调填 `http://127.0.0.1:17890/baidu/`（本机监听，不要改成官网域名，除非同时改 json 和本机监听）。
2. 客户在 **云备份 → 百度网盘** 点 **扫码授权** 或 **帐号密码**，token 加密存在本机，不上传网站。成功后授权窗自动关闭。
3. 发布安装包时：复制 example 为 `BaiduApp.json`，填真实 Key，Client 和 Engine **各放一份**（或同一目录共用一份）。
4. 分片固定 4MB（接口要求，非末片不能更小）。续传 JSON 与分片 `.log` 在程序旁 `data\baidu-upload\`。
5. 端口 17890 被占用时授权失败，先关掉占用再授权。

## 3. 检查

| 项 | 期望 |
| --- | --- |
| 续费页点支付宝 | 跳出支付宝收银台，不是「先配置异步通知」 |
| 支付完成 | 订单变已支付；支付宝商户后台能看到异步通知成功 |
| 退款 | 厂商/订单退款能到支付宝 |
| 客户端点百度授权 | 打开扫码或帐号密码窗；缺 json 则「未配置百度应用」；成功后窗关闭 |
| 授权后勾启用 | 任务云上传能选百度 |
