## 1. 目标

- 去掉「全文居中堆叠」观感，首屏改为左文右图。
- 用真实客户端截图建立产品可信度。
- 文案对标灾备竞品结构，但叙事差异化：**本机加密 + 离线介质拷贝与离线**。
- 全站对外可见 logo 统一为 PNG。

---

## 2. 页面结构

### 2.1 首屏

| 左侧 | 右侧 |
| --- | --- |
| `logo.png`（品牌主信号） | `product1.png` 全幅产品界面 |
| 产品名 **用心云·循备** | 无浮层徽章、无促销贴纸 |
| Headline：本机加密备份 + 离线介质兜底 | |
| 一句支撑：勒索场景下在线备份不够 | |
| CTA：下载客户端 · 申请账号 | |

导航：左 logo，右登录/注册；墨色氛围。

### 2.2 第二屏：价格

- 数据源：现有 `GET /api/public/price`。
- 区块标题左对齐；三列价目；不占首屏。

### 2.3 价值区（约 6 点）

1. **离线介质**（主差异）— 登记 USB/移动盘，到点拷包并按级别离线  
2. **本机加密打包** — 文件与 SQL Server / MySQL 打 zip，日志留本机  
3. **恢复入口** — 客户端侧栏恢复  
4. **授权与设备** — 三档按同时登录设备数  
5. **云与传输（可选）** — 授权有效时可再传七牛/UNC/FTP  
6. **无网仍跑离线任务** — 已保存的介质任务到点仍执行  

布局：左对齐列表或 2×3 疏排，非居中卡片墙。

### 2.4 实景截图（左右交替）

| 顺序 | 图 | 文案焦点 |
| --- | --- | --- |
| 1 | `product4.png` | 登记介质：序列号/签名/容量 |
| 2 | `product3.png` | 介质任务：开始时间、离线时间、保留 |
| 3 | `product2.png` | 文件 / MSSQL / MySQL 任务 |
| 4 | `product5.png` 或 `product6.png`（择一清晰） | 引擎或其它清晰实景 |

勒索通报短述可保留为一小节，不占首屏。

### 2.5 下载 + 页脚

保留公司信息、备案、协议链接；下载按钮指向现有 zip 地址。
