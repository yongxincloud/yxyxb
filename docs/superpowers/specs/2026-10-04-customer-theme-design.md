# 客户站墨底红印设计

**日期：** 2026-10-04  
**状态：** 待审阅  
**范围：** 营销网站、客户登录、登录后信息

## 目标

客户能在营销首页、登录页和登录后页面看到用心云 logo，以及与 logo 一致的墨色加正红。登录后的「我的订阅」写明授权覆盖哪些能力。操作步骤仍在客户端里完成。

厂商后台保持现在的蓝色。桌面客户端不改。

## 已确认的样子

配色按已看过的预览页「墨底红印」：

| 用途 | 色值 |
| --- | --- |
| 按钮、主操作 | `#DC0606`，悬停 `#B00404` |
| 文字链接、当前菜单文字 | `#B10505` |
| 当前菜单底 | `#F8E8E8` |
| 营销首屏、登录左侧、页脚 | `#1C1214` |
| 页面底 | `#F6F3F1` |
| 卡片 | `#FFFFFF` |
| 标题 | `#2A211F` |
| 正文 | `#5C534F` |
| 次要文字 | `#8A817C` |
| 边框 | `#E6E0DC` |
| 错误文字 | `#7A1F1A` |

Logo 用 `src/Yxy.img/logo.jpg`。图片是白底，深色区域用白卡片托住。

## 架构

`src/Yxy.Web/src/styles/tokens.css` 里的 `:root` 继续给厂商后台用，现有蓝色变量不改。

`App.vue` 根据当前路由给 `document.body` 添加或去掉 `theme-customer`。路径以 `/vendor` 开头时不加。类名加在 `body` 上，页面底色才能铺满整页，离开客户页时也不会把客户色留在厂商页上。

`body.theme-customer` 覆盖这些已有变量：

- `--brand-primary` 为 `#B10505`，供文字链接使用。
- `--c-hero-from` 与 `--c-hero-to` 为 `#1C1214`。
- `--c-footer` 为 `#1C1214`。
- `--c-portal-bg` 与 `--c-surface-alt` 为 `#F6F3F1`。
- `--c-title` 为 `#2A211F`，`--c-text` 为 `#5C534F`，`--c-text-muted` 为 `#8A817C`，`--c-border` 为 `#E6E0DC`，`--c-danger` 为 `#7A1F1A`。

按钮 `.btn-yxy` 和登录页选中的标签使用 `#DC0606`，悬停 `#B00404`。客户页不再用 `--brand-cyan` 做悬停。`PortalLayout.vue` 当前菜单底从 `#eef3ff` 改为 `#F8E8E8`，文字用 `#B10505`。`VendorLayout.vue` 的 `#eef3ff` 不改。

不新增接口。订阅状态仍来自现有 `GET /api/portal/subscription`。授权覆盖说明是页面上的固定文字。

## 组件

### Logo

把 `src/Yxy.img/logo.jpg` 复制到 `src/Yxy.Web/public/logo.jpg`，页面用 `/logo.jpg`。替代文字为「用心云」。

只在这三处放图，图片保持原比例：

1. `HomeView.vue` 顶栏，高度 64px，替换文字「用心云循备」。
2. `LoginView.vue` 左侧深色区域，高度 64px，图片放在白底圆角卡片上。
3. `PortalLayout.vue` 左侧栏，高度 72px，放在邮箱上方。

注册、找回密码、协议、隐私、找不到页面不新增 logo，只继承客户配色。

### 我的订阅

`PortalView.vue` 在订阅数据加载成功后，保留现有三格（授权状态、到期日、下次联网校验）和现有那句有效或无效说明。在这句下面增加固定列表：

- 文件备份
- 库备份（SQL Server）
- 离线介质
- 云、UNC、FTP、邮件

列表后再加一句：「没有有效授权时，文件备份、库备份、云、UNC、FTP、邮件会停用。离线介质仍可使用。操作在客户端里做。」

未登录或接口失败时仍只显示现有错误「请先登录」，不显示列表。续费按钮和其余登录后页面的文案不改。

### 跟着换色的页面

这些页面不改文案和版式，只因为挂在 `theme-customer` 上而换成新颜色：`/`、`/register`、`/login`、`/forgot`、`/terms`、`/privacy`、`/home` 及其子页面、找不到页面。

`/vendor` 与 `/vendor/login` 排除在外。

## 错误处理

客户页面的错误文字用 `#7A1F1A`，和按钮红 `#DC0606` 分开。厂商后台的错误色保持 `#F14E4E`。

登录失败、验证码失败、订阅读取失败沿用现有文案和现有跳转，不新增错误分支。

## 测试

实现后用浏览器核对，不新增 API 测试：

1. `/` 顶栏是 logo，首屏和页脚是墨色，购买按钮是 `#DC0606`。
2. `/login` 左侧是墨色，logo 在白卡片上，登录按钮是正红，错误文字是 `#7A1F1A`。
3. 登录后 `/home` 左侧有 logo，「我的订阅」有四条授权说明和停用说明。
4. `/vendor/login` 主按钮仍是现在的蓝 `#3171FF`。
5. `/register` 主按钮是正红，页面上没有新的 logo。

## 不做

- 不改厂商后台的颜色、布局和文案。
- 不改桌面客户端。
- 不改营销首页、登录页除 logo 以外的文案。
- 不把操作手册的操作步骤写进网页。
- 不重排现有版式。
