## 做了什么

### 客户端

1. **去掉「工具」菜单**；「恢复」从占位改为可用页。
2. **数据库恢复（本期范围）**
   - MSSQL：选实例 + `.zip`（内含 `.bak`）或 `.bak`；目标库名、压缩密码、可选覆盖。
   - MySQL：选实例 + `.zip`（内含 `.sql`）或 `.sql`；需本机 `mysql.exe`。
   - 解压：`ZipPacker.ExtractFirst`；MSSQL 临时 `.bak` 放在公共目录供服务账号读取。
3. **我的设备**：侧栏独立列表页（同任务/实例），行内踢出；踢本机后直接注销回首页（无二次弹窗）。
4. **授权展示**：首页与设备页显示版本名与最大设备数；登录与拉设备列表时写入 `site.session`。

### 网站 / 厂商

1. 厂商「客户」：可改账号类型（产品档），操作日志 `customer/edition`。
2. 营销首页文案居中；申请账号页左右分栏（介绍 + 表单），对齐厂商登录布局。
3. 下载/登录文案去掉「不限台数」口径。

### API

- `POST /api/vendor/customers/{id}/edition`
- 客户端登录 / 设备列表返回 `productNo`、`productName`、`maxDevices`
