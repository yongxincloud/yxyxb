## 做了什么

1. **三档产品**：个人 / 标准 / 专业（`PERSONAL` / `STANDARD` / `PRO`），默认设备上限 3 / 10 / 50，原价 36 / 98 / 198。
2. **定价与促销**：后台可改原价、促销价与窗口、`MaxDevices`；公开接口 `GET /api/public/price` 返回 `plans[]`。
3. **设备占坑**：客户端登录写入 `AccountDevices`；退出不释放；门户与客户端可踢出（踢后 token 失效）。
4. **设备名称**：登录上报 `电脑名 · MAC · Windows用户`，门户「我的设备」优先展示该名称，设备 ID 仍保留作唯一键。
5. **升级补差**：周期内升档按剩余天数补差价，到期日不变；续费降档前若设备超新上限则拦截。
6. **试用**：仍不限台数；正式授权才限台。
7. **前端**：首页三列定价；订单选档/升级；门户「我的设备」；厂商产品编辑页。
8. **文档**：PRD / 后台需求中「不限台数」口径已改为三档设备上限。
9. **合入后跟进（同日）**：客户端设备列表页、授权版本展示、厂商改账号类型、库恢复页、营销页布局；详见跟进总结。

## 本机联调要点

- API：`http://127.0.0.1:5080`
- Web：`http://127.0.0.1:5173`（代理 `/api`）
- 测试客户端以程序目录为准：`D:\yxyxb\`
- `data/site.url` 必须指向本机 API，否则设备不会出现在本地门户
- 设备名称需用**带新逻辑的客户端**重新登录后才会写入
- 仓库内 `bin` / `obj` / `dist` / `publish` / `.worktrees` 为可删编译产物，勿当发布源
