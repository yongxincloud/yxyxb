# W1 网站骨架与账号 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在现有 `yongxinyunbak` 解决方案里新增 ASP.NET Core 8 Web API 和 Vue 3 前端，使客户能用邮箱注册、用密码或邮箱验证码登录、用邮箱验证码重置密码。

**Architecture:** `YxyXb.Api` 是独立的 `net8.0` Web API，只返回 JSON，不引用桌面端 `net48` 工程。账号规则放在 `AccountService`、`EmailCodeService`、`CaptchaService`。`YxyXb.Web` 是 Vite + Vue 3 工程，用 Vue Router 做页面，开发时把 `/api` 代理到 API。开发库是本地 SQLite 文件，EF Core `EnsureCreated` 建表。API 测试用 `WebApplicationFactory`。邮件用内存假发送器。测试环境图形验证码答案固定为 `0000`。登录成功写 HttpOnly Cookie，前端再请求 `/api/account/me` 显示邮箱。

**Tech Stack:** Vue 3 + Vite + Vue Router、ASP.NET Core 8 Web API、EF Core 8 + SQLite、BCrypt.Net-Next、NUnit、Microsoft.AspNetCore.Mvc.Testing、Vitest。

本计划替换原先的 Razor / MVC 方案。`src/YxyXb.Web` 的 C# 工程已经不在磁盘上，但 `YxyXb.sln` 仍引用它。`tests/YxyXb.Web.Tests` 仍按表单页面编写，Task 1 删掉这两处，不要在其上继续加 Razor。

## Global Constraints

- 网站 API 目标框架 `net8.0`。桌面端 `YxyXb.Client` / `YxyXb.Engine` 保持 `net48`，本计划不改那些项目。
- 页面全部是 Vue 3 单文件组件。不创建 `.cshtml`，不调用 `AddControllersWithViews`。
- 开发连接串：`Data Source=yxy-api.db`（相对 API 内容根）。不连接 Turso，不使用 MySQL。
- API 开发地址固定 `http://127.0.0.1:5080`。Vue 开发地址 `http://127.0.0.1:5173`，只通过代理访问 API。
- 密码：BCrypt，work factor 12。不存明文，页面不回显密码。
- 密码强度（需求只写「密码强度」，W1 锁定为）：至少 8 位，且同时含字母和数字。
- 邮箱入库前 `Trim().ToLowerInvariant()`。唯一约束加在规范化后的邮箱上。
- 邮箱验证码：6 位数字，5 分钟有效，用后作废。场景只有 `register`、`login`、`reset`。
- 同邮箱 60 秒内只能发 1 条（跨场景）。同一邮箱 UTC 自然日最多 10 条。
- 同一 IP 每小时最多发送 30 条验证码、最多提交 10 次注册。需求只写「同 IP 限频」，这两个数字是 W1 锁定值。
- 密码登录连续失败 5 次后锁定 15 分钟。失败文案一律 `邮箱或密码错误`。锁定文案 `登录已锁定，请 15 分钟后再试`。验证码登录失败文案一律 `邮箱或验证码错误`。
- 注册字段只有邮箱、密码、确认密码、邮箱验证码、图形验证码。手机号列保留但注册页不收集。
- 注册链接 `?provider_no=`：仅当存在 `status = 1` 的服务商时写入 `customer.direct_provider_id`。无效、禁用、冻结都不阻止注册，归属留空（归厂商）。
- 图形验证码只挡发注册码。注册提交靠已经发出的邮箱验证码，不再消耗第二张图形验证码。
- 已注册邮箱请求注册验证码、未注册邮箱请求登录或重置验证码：HTTP 200 且 `ok: true`，不发信，避免探测邮箱。
- 厂商后台不能新建账号。本计划不建后台页面。
- 不做客户端四个接口、订单、支付、介绍主页、服务商申请页、扫码登录。
- 登录成功后进入 `/home`，只显示邮箱。`/` 只放「用心云循备」和注册/登录入口。介绍主页留给 W4，W1 不预渲染。
- 设计令牌数值以需求文档 §8.2、§8.3 为准，写入 `src/YxyXb.Web/src/styles/tokens.css`。
- JSON 字段用 camelCase。失败响应 HTTP 400，正文 `{ "ok": false, "error": "..." }`。成功 HTTP 200，正文 `{ "ok": true, "error": null }`。需要回显邮箱时带 `email`。

```csharp
using YxyXb.Api.Data;

namespace YxyXb.Api.Services;

public sealed record IssueCodeResult(bool Ok, string? Code, string? Error);

public sealed class EmailCodeService
{
    public const int LifetimeMinutes = 5;
    public const int MinIntervalSeconds = 60;
    public const int DailyCap = 10;
    public const int IpHourlyCap = 30;

    private readonly WebDb _db;
    private readonly TimeProvider _time;
    public EmailCodeService(WebDb db, TimeProvider time) { _db = db; _time = time; }

    public async Task<IssueCodeResult> IssueAsync(string email, string scene, string? ip)
    {
        var now = _time.GetUtcNow().UtcDateTime;
        var last = _db.EmailCodes.Where(x => x.Email == email).OrderByDescending(x => x.CreatedAt).FirstOrDefault();
        if (last != null && (now - last.CreatedAt).TotalSeconds < MinIntervalSeconds)
            return new IssueCodeResult(false, null, "too_soon");
        var dayStart = now.Date;
        var sentToday = _db.EmailCodes.Count(x => x.Email == email && x.CreatedAt >= dayStart);
        if (sentToday >= DailyCap) return new IssueCodeResult(false, null, "daily_cap");
        if (!string.IsNullOrEmpty(ip))
        {
            var hourAgo = now.AddHours(-1);
            var ipCount = _db.EmailCodes.Count(x => x.ReqIp == ip && x.CreatedAt >= hourAgo);
            if (ipCount >= IpHourlyCap) return new IssueCodeResult(false, null, "ip_cap");
        }
        var code = Random.Shared.Next(0, 1000000).ToString("D6");
        _db.EmailCodes.Add(new EmailCodeRow
        {
            Email = email, Code = code, Scene = scene, Used = 0,
            ExpiresAt = now.AddMinutes(LifetimeMinutes), ReqIp = ip, CreatedAt = now
        });
        await _db.SaveChangesAsync();
        return new IssueCodeResult(true, code, null);
    }

    public async Task<bool> ConsumeAsync(string email, string scene, string code)
    {
        var now = _time.GetUtcNow().UtcDateTime;
        var row = _db.EmailCodes
            .Where(x => x.Email == email && x.Scene == scene && x.Code == code && x.Used == 0 && x.ExpiresAt >= now)
            .OrderByDescending(x => x.Id).FirstOrDefault();
        if (row == null) return false;
        row.Used = 1;
        await _db.SaveChangesAsync();
        return true;
    }
}
```

```csharp
using Microsoft.Extensions.Caching.Memory;
using Microsoft.Extensions.Hosting;

namespace YxyXb.Api.Services;

public sealed record CaptchaView(string Id, string Svg);

public sealed class CaptchaService
{
    private readonly IMemoryCache _cache;
    private readonly bool _testing;
    public CaptchaService(IMemoryCache cache, IHostEnvironment env)
    {
        _cache = cache;
        _testing = env.IsEnvironment("Testing");
    }

    public CaptchaView Create()
    {
        var answer = _testing ? "0000" : Random.Shared.Next(0, 10000).ToString("D4");
        var id = Guid.NewGuid().ToString("N");
        _cache.Set("captcha:" + id, answer, TimeSpan.FromMinutes(5));
        var svg = "<svg xmlns=\"http://www.w3.org/2000/svg\" width=\"120\" height=\"40\"><rect width=\"120\" height=\"40\" fill=\"#F6F6F6\"/>";
        svg += _testing
            ? "<text x=\"16\" y=\"28\" font-size=\"24\" fill=\"#3171FF\">****</text>"
            : "<text x=\"16\" y=\"28\" font-size=\"24\" fill=\"#3171FF\">" + answer + "</text>";
        svg += "</svg>";
        return new CaptchaView(id, svg);
    }

    public bool VerifyAndConsume(string? id, string? answer)
    {
        if (string.IsNullOrEmpty(id)) return false;
        var key = "captcha:" + id;
        var ok = _cache.TryGetValue(key, out string? stored) && stored == (answer ?? "");
        _cache.Remove(key);
        return ok;
    }
}
```

```csharp
using YxyXb.Api.Data;

namespace YxyXb.Api.Services;

public sealed record RegisterInput(string? Email, string? Password, string? Confirm, string? EmailCode, string? ProviderNo);
public sealed record AuthResult(bool Ok, string? Error, long? AccountId = null, string? Email = null);

public sealed class AccountService
{
    private readonly WebDb _db;
    private readonly IPasswordHasher _hasher;
    private readonly EmailCodeService _codes;
    private readonly CaptchaService _captcha;
    private readonly IEmailSender _mail;
    private readonly TimeProvider _time;

    public AccountService(WebDb db, IPasswordHasher hasher, EmailCodeService codes, CaptchaService captcha, IEmailSender mail, TimeProvider time)
    {
        _db = db; _hasher = hasher; _codes = codes; _captcha = captcha; _mail = mail; _time = time;
    }

    public async Task<AuthResult> SendCodeAsync(string? emailRaw, string? scene, string? captchaId, string? captchaAnswer, string? ip)
    {
        var email = Norm(emailRaw);
        if (scene is not ("register" or "login" or "reset")) return Fail("场景不正确");
        if (scene == "register" && !_captcha.VerifyAndConsume(captchaId, captchaAnswer))
            return Fail("图形验证码错误");
        var exists = await _db.Accounts.AnyAsync(x => x.Email == email);
        if (scene == "register" && exists) return new AuthResult(true, null);
        if (scene is "login" or "reset" && !exists) return new AuthResult(true, null);
        var issued = await _codes.IssueAsync(email, scene, ip);
        if (!issued.Ok)
            return Fail(issued.Error == "too_soon" ? "发送过于频繁" : "今日发送次数已达上限");
        await _mail.SendAsync(email, "用心云·循备验证码", "验证码 " + issued.Code + " ，5 分钟内有效。");
        return new AuthResult(true, null);
    }

    public async Task<AuthResult> RegisterAsync(RegisterInput input, string? ip)
    {
        var email = Norm(input.Email);
        if (!IsEmail(email)) return Fail("邮箱格式不正确");
        if (input.Password != input.Confirm) return Fail("两次密码不一致");
        if (!PasswordRules.IsStrong(input.Password)) return Fail("密码至少 8 位且同时包含字母和数字");
        if (await IpRegisterCapped(ip)) return Fail("注册过于频繁");
        if (await _db.Accounts.AnyAsync(x => x.Email == email)) return Fail("该邮箱已注册");
        if (!await _codes.ConsumeAsync(email, "register", input.EmailCode ?? ""))
            return Fail("邮箱或验证码错误");
        var now = _time.GetUtcNow().UtcDateTime;
        var account = new Account
        {
            Email = email,
            PasswordHash = _hasher.Hash(input.Password!),
            Status = 1,
            CreatedAt = now,
            UpdatedAt = now
        };
        _db.Accounts.Add(account);
        await _db.SaveChangesAsync();
        long? providerId = null;
        if (!string.IsNullOrWhiteSpace(input.ProviderNo))
        {
            var provider = await _db.Providers.SingleOrDefaultAsync(x => x.ProviderNo == input.ProviderNo && x.Status == 1);
            providerId = provider?.Id;
        }
        _db.Customers.Add(new Customer
        {
            CustomerNo = "C" + now.ToString("yyyyMMddHHmmssfff"),
            AccountId = account.Id,
            DirectProviderId = providerId,
            Status = 1,
            CreatedAt = now,
            UpdatedAt = now
        });
        await _db.SaveChangesAsync();
        return new AuthResult(true, null, account.Id, account.Email);
    }

    async Task<bool> IpRegisterCapped(string? ip)
    {
        if (string.IsNullOrEmpty(ip)) return false;
        var hourAgo = _time.GetUtcNow().UtcDateTime.AddHours(-1);
        var count = await _db.EmailCodes.CountAsync(x => x.Scene == "register" && x.ReqIp == ip && x.Used == 1 && x.CreatedAt >= hourAgo);
        return count >= 10;
    }

    internal static string Norm(string? email) => (email ?? "").Trim().ToLowerInvariant();
    static bool IsEmail(string email)
    {
        try { return new MailAddress(email).Address == email && email.Contains('@'); }
        catch { return false; }
    }
    static AuthResult Fail(string error) => new(false, error);
}

public static class PasswordRules
{
    public static bool IsStrong(string? password)
    {
        if (string.IsNullOrEmpty(password) || password.Length < 8) return false;
        return password.Any(char.IsLetter) && password.Any(char.IsDigit);
    }
}
```

```csharp
public async Task<AuthResult> LoginPasswordAsync(string? emailRaw, string? password, string? ip)
{
    var email = Norm(emailRaw);
    if (await IsLocked(email, "password"))
        return Fail("登录已锁定，请 15 分钟后再试");
    var account = await _db.Accounts.SingleOrDefaultAsync(x => x.Email == email);
    if (account == null || account.Status != 1 || !_hasher.Verify(password ?? "", account.PasswordHash))
    {
        await WriteLog(account?.Id, email, "password", ip, 0);
        return Fail("邮箱或密码错误");
    }
    await WriteLog(account.Id, email, "password", ip, 1);
    var now = _time.GetUtcNow().UtcDateTime;
    account.LastLoginAt = now;
    account.UpdatedAt = now;
    await _db.SaveChangesAsync();
    return new AuthResult(true, null, account.Id, account.Email);
}

async Task<bool> IsLocked(string email, string way)
{
    var now = _time.GetUtcNow().UtcDateTime;
    var recent = await _db.LoginLogs.Where(x => x.Email == email && x.Way == way)
        .OrderByDescending(x => x.Id).Take(5).ToListAsync();
    if (recent.Count < 5 || recent.Any(x => x.Success == 1)) return false;
    return recent[0].CreatedAt.AddMinutes(15) > now;
}

async Task WriteLog(long? accountId, string email, string way, string? ip, int success)
{
    _db.LoginLogs.Add(new AccountLoginLog
    {
        AccountId = accountId,
        Email = email,
        Way = way,
        Ip = ip,
        Success = success,
        CreatedAt = _time.GetUtcNow().UtcDateTime
    });
    await _db.SaveChangesAsync();
}
```

```csharp
public async Task<AuthResult> ResetPasswordAsync(string? emailRaw, string? code, string? password, string? confirm)
{
    var email = Norm(emailRaw);
    if (password != confirm) return Fail("两次密码不一致");
    if (!PasswordRules.IsStrong(password)) return Fail("密码至少 8 位且同时包含字母和数字");
    if (!await _codes.ConsumeAsync(email, "reset", code ?? ""))
        return Fail("邮箱或验证码错误");
    var account = await _db.Accounts.SingleOrDefaultAsync(x => x.Email == email);
    if (account == null) return Fail("邮箱或验证码错误");
    account.PasswordHash = _hasher.Hash(password!);
    account.UpdatedAt = _time.GetUtcNow().UtcDateTime;
    await _db.SaveChangesAsync();
    return new AuthResult(true, null, account.Id, account.Email);
}
```

```js
import { readdirSync, readFileSync, statSync } from 'node:fs'
import { dirname, join } from 'node:path'
import { fileURLToPath } from 'node:url'
import { expect, test } from 'vitest'

function filesUnder(dir) {
  const found = []
  for (const name of readdirSync(dir)) {
    const path = join(dir, name)
    if (statSync(path).isDirectory()) found.push(...filesUnder(path))
    else if (name.endsWith('.vue') || name.endsWith('.html') || name.endsWith('.js')) found.push(path)
  }
  return found
}

test('account screens have no social login', () => {
  const root = dirname(fileURLToPath(import.meta.url))
  const banned = ['微信', '支付宝', 'weixin', 'alipay', 'qq.com']
  const paths = [...filesUnder(root), join(root, '../index.html')]
  for (const path of paths) {
    if (path.endsWith('no-social.test.js')) continue
    const text = readFileSync(path, 'utf8').toLowerCase()
    for (const word of banned) expect(text, path).not.toContain(word.toLowerCase())
  }
})
```
