# Windows 客户端自动更新发布清单

## 版本与构建

1. 修改 `ReleaseVersion`，确认远程 `version.json` 使用相同的三段版本号。
2. 从当前完整工作区执行 Release 构建；客户端或服务运行导致 `dist` 被锁定时，改用独立 Release 输出目录。
3. 构建成功后运行全仓测试，至少确认计划、云和离线介质测试通过。

## 更新包内容

1. 包含客户端、任务引擎、更新器及全部运行依赖。
2. 包含 32 位和 64 位 `SQLite.Interop.dll`。
3. **必须包含正式的 `BaiduApp.json`**，否则新客户无法使用百度网盘。该文件不得提交到 Git，也不得在日志或发布说明中输出密钥。
4. 更新器遇到客户端已有 `BaiduApp.json` 时保留现有文件；只有缺失时才从更新包补齐。
5. 不包含 `oem.json`、用户 `data/`、数据库、备份包、测试程序、PDB、API 或本机 `appsettings.Local.json`。

## 上传顺序

1. 先上传更新 ZIP。
2. 校验远程 ZIP 大小和 SHA256 与本地一致。
3. 最后上传 `version.json`，避免客户端在 ZIP 未完成时开始升级。

## 验收

1. 确认客户端显示的 `ReleaseVersion` 正确。
2. 在一份旧版本副本上验证更新器下载、哈希校验、停止引擎、替换文件、启动引擎和重新打开客户端。
3. 确认更新前后 `data/`、`oem.json` 和已有 `BaiduApp.json` 未被删除或覆盖。
4. 确认新安装环境包含 `BaiduApp.json`，百度网盘授权与上传可用。
