# 咨询论坛采用官方方法与客户问答混合模式

**Status**: accepted

咨询论坛同时承载官方发布的可复用方法文章和注册客户发起的公开咨询主题，访客可以阅读，注册客户可以参与交流。采用混合模式，是因为纯论坛难以形成稳定、可索引的知识页面，而纯官方博客又缺少客户围绕真实问题补充经验和确认答案的能力。咨询论坛是现有客服渠道的补充，不承接账号、订单、凭据或客户业务数据等不适合公开的问题。

## Consequences

- 公开内容必须经过审核后才能展示和进入搜索索引。
- 新账号的咨询主题需要预审，运营方必须承担持续的内容治理投入。
- 方法文章与咨询主题需要分别建模，避免把官方说明和客户回复混为同一类内容。
